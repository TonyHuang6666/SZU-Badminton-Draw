# 赛程编排说明

赛程编排把已确认的对阵安排到具体日期、时间和场地。整场赛事使用一份资源设置；单项目和多项目都在“安排赛程”中生成，在独立赛程板中查看和调整。完整办赛流程及材料填写见[使用说明](usage.md)。

## 进入条件与状态

先完成所有项目的名单导入和抽签确认，再点击“继续安排比赛时间”。以“先完成公开抽签”创建的比赛会在此时转入完整筹备，已确认签表保留。

赛事进度按已保存数据显示：

| 状态 | 含义 |
| --- | --- |
| 草稿 | 正在准备项目和名单。 |
| 名单就绪 | 全部名单有效，可执行公开抽签。 |
| 抽签已确认 | 全部项目签表和比赛关系已确认。 |
| 赛程就绪 | 全部真实比赛已排定，并通过校验。 |
| 进行中 | 已保存部分有效赛果。 |
| 已完成 | 全部真实比赛都有有效赛果。 |

尚无赛果时，可修改设置并重新生成整场赛程。已有赛果后，使用赛程板调整未完成比赛；已完成比赛的位置锁定。

## 资源只设置一份

排程设置由比赛日、场地、裁判容量、项目时长组成。单项赛另设置选手最少休息和每日场次上限，所有兼项按同一身份合计。

### 比赛日期与开放时间

每个比赛日填写“比赛日期”“每天开始”“每天结束”，并选择当天场地。日期须唯一，结束时间须晚于开始时间，一场比赛须完整落在当天开放时段内。

点击日期框或日历图标打开日历，箭头切换月份，顶部年月可切换到月份或年份选择；选中日期后收起。键盘可用 Tab 聚焦、空格或 Enter 打开、Esc 取消。点击时间框后选择 24 小时制的小时与分钟，再点击“确认”；取消、Esc 或点击外部会保留原值。

“添加比赛日”把新卡片放到顶部，默认取已有有效日期中最晚一天的次日。修改日期时卡片保持原位；重新载入设置后，卡片按日期由晚到早显示。实际排程、最后比赛日判断和导出均按日期先后处理。“移除这一天”移除当前草稿中的日期。

例如，可将比赛分为：

| 日期 | 开放时间 | 资源用途 |
| --- | --- | --- |
| 2026-10-10 | 09:00–18:00 | 场地较充足，安排较多早期轮次。 |
| 2026-10-11 | 09:00–18:00 | 继续推进各项目。 |
| 2026-10-17 | 14:00–18:00 | 使用已预约场地完成后续比赛及决赛。 |

这些输入先保存在页面草稿中，点击“检查并生成赛程”且成功后才写入赛事文件。

### 场馆和场地

每个比赛日点击“选择场馆与场地”，勾选当天实际可用的场地：

| 校区 | 场馆 | 可选场地 |
| --- | --- | --- |
| 粤海 | 运动广场东馆羽毛球场 | A1–A8、B1–B8、C1–C8、D1–D8，共 32 片 |
| 丽湖 | 至快体育馆 | 1–12 号场 |
| 丽湖 | 至畅体育馆 | 1–10 号场 |

东馆可按 A、B、C、D 区选择，其他场馆按数字顺序选择，也可全选或清空。新比赛日的场地默认为空。内置清单用于选择名称，实际预约和开放情况由组织方核实。

导出使用“粤海东馆 · A1”“丽湖至快 · 1号场”等带馆名的名称；每日赛程 Excel 的参数表还列出实际使用的内置场馆全名，便于现场识别。

选择“自定义场馆”可填写场馆名和场地名称。场地每行一个，也支持中英文逗号和分号。输入数量后可“生成编号场地”，从 1 号场到 N 号场，最多 256 片；已有内容时按钮显示“替换为编号场地”。场馆名可留空以保留自由场地名。

“沿用上一个比赛日的场地和时间”取日期早于当前日且最接近的一天，在选择窗口核对后，一并带入其场地、开始和结束时间。当前日期保留，不可用时段和裁判时段仍按当前日设置。取消或关闭选择窗口保留原草稿；确认场地后仍需成功生成赛程才保存。

程序按场地名称和时间校验资源；跨校区交通、校区预选和阶段指定场馆需要组织方另行安排。

### 不可用场地时段

在“高级排程设置 → 每天的特殊安排 → 不可用场地时段”中添加起止时间，点击“选择不可用场地…”从当天场地中勾选。时间按 `HH:mm` 填写，并落在当天开放时段内。

例如，C 区两片场在 12:00–13:00 维护，可选择对应场地并添加该时段。需要全场午休时，选择“当天全部场地”。空选择与全场暂停是两个不同状态，请使用明确的全场选项。

更换场馆或减少场地影响已有时段时，选择窗口列出影响并要求确认：保留仍被选用的场地，删除已无剩余场地的那条时段。“当天全部场地”的暂停继续作用于新选场地。

### 裁判人数与并发容量

“裁判人数”填写整场赛事的并发上限，留空时按场地数计算。例如 16 片场、6 名裁判，同一时刻最多进行 6 场比赛。

“分时段裁判人数”可进一步限制某天某个时段的人数，按起止时间和可用人数填写。实际并发取当时可用场地、全局裁判人数及适用分时人数中的最小值；分时人数为 0 表示暂停比赛。分时配置用于收紧相应时段，安排更多裁判时也要同时核对全局人数。

程序检查整个比赛占用区间的容量。若 12:00 起裁判减少，跨越 12:00 的比赛同样计入该时段。这里只管理可同时进行的场次数，具体裁判名单、轮换和执裁休息由裁判长安排。

### 单场时长与分段时长

各项目的“基础单场时长 · 分钟”包含热身、比赛和换场，选手场间休息另行计算。不同项目可设置不同预计时长。

单项淘汰赛可在“分段比赛时长”勾选“进入前 N 名起使用不同的比赛时长”，填写分界人数和“此后每场时长 · 分钟”。例如：

| 设置 | 对应比赛 |
| --- | --- |
| 基础 20 分钟 | 32 进 16 及更早轮次 |
| 从前 16 名开始、此后 30 分钟 | 16 进 8、8 进 4、半决赛、决赛，以及排位赛 |

关闭分段后，全部场次使用基础时长。循环赛和团体赛使用基础时长。团体项目的一个比赛节点表示两队的一场完整对抗，因此填写的是包含各盘比赛的总占用时间；队员名单、子场顺序和并行执裁需另外组织。

### 选手休息与每日上限

单项赛的“选手最少休息 · 分钟”初始为 30，“每位选手每天最多场次”初始为 4。组织方应按本场赛事规程、强度和可用日期确定值。

休息从上一场计划结束到下一场计划开始计算。例如一场 10:00–10:20，最少休息 30 分钟，则该选手下一场最早 10:50 开始。跨日期的间隔按真实日期计算。

每日上限按同一自然日、所有项目合计。若某人当天打两场单打、一场双打，在上限 4 场的设置下，还可安排一场相容的后续比赛。双打两名选手分别参加检查；优先使用学号，缺失时使用姓名。

团体赛按队伍检查重叠和前后依赖，界面不启用个人最少休息、个人每日上限或分段时长。团体赛内部队员的个人负荷由裁判长核对。

## 硬约束与策略分开

点击“检查并生成赛程”后，程序优先选择较早的合法位置，让整场比赛尽快完成。所有成功保存的自动赛程须满足：

1. 覆盖全部真实比赛；轮空直接晋级不占用一个比赛时段。
2. 后续比赛开始不早于其全部来源比赛结束。
3. 同一场地的占用不重叠，比赛处于开放范围内，并避开不可用时段。
4. 同时进行的比赛数量满足场地及裁判容量。
5. 同一选手或队伍在可能实际发生的晋级路径上不撞场；单项赛还满足全赛事最少休息和每日上限。
6. 已完成或锁定比赛的位置保持固定。
7. 同项目名次赛的开始时间不晚于冠军决赛开始时间。
8. 启用决赛最后一天时，相关冠亚军决赛安排在日期最晚的比赛日。

“可能实际发生的晋级路径”会考虑胜者线和负者线的关系。例如某人不能既作为同一场的胜者又作为该场的负者继续晋级，这两条互斥路径按各自可能性检查。尚未决出的“某场胜者／负者”也参与约束校验。

多项目页面提供“将各项目决赛安排在最后一个比赛日”，初始未勾选。勾选后，冠亚军决赛必须在所填日期中最晚的一天进行；半决赛、季军赛和其他排位赛仍按合法位置尽早安排。只有一天时要求自然满足；只有小组出线、没有冠亚军决赛的项目按其自身比赛结构安排。

末日容量不足时，需要调整资源或由组织方决定是否取消该选项。成功保存后，手动移动、连锁和撤销同样检查决赛日期要求。

日容量和利用率有助于判断资源是否充足，但合法赛程还受依赖和选手负荷影响。搜索优先级用于选择合法位置，程序不保证找到数学上的最优赛程。算法细节见[算法说明](algorithm.md)。

### 修改设置与重新生成

修改日期、场地、时间或高级设置后，点击“检查并生成赛程”提交。完整排程和校验成功才保存；失败时保留原有合法赛程。

点击“放弃未保存的修改”，再选择“放弃修改”，可恢复已保存的排程设置；没有已保存设置时恢复初始值。选择“继续编辑”、Esc 或关闭确认窗口保留草稿。折叠高级设置只改变显示。

如果提示草稿与当前赛事冲突，说明签表、资源或赛程已被其他有效操作更新。通过“放弃未保存的修改”恢复当前设置，再继续编辑。赛程板里已经保存的手动调整保持有效。

## 求解失败不等于数学上无解

失败页按未安排场次、约束原因、容量和建议说明结果。优先读摘要，再按需要展开核对详情：

| 提示类型 | 含义与处理 |
| --- | --- |
| 输入无效 | 检查日期重复、结束时间、空场地、时段范围、裁判人数或项目时长等。 |
| 已证明容量矛盾 | 查看是哪一种资源不足，据此增加日期、时间、场地或裁判。 |
| 本次搜索未找到 | 本次有限搜索没有完成；结合诊断调整资源后再生成。 |
| 验证未完成 | 候选安排尚未完成全部硬校验，不能作为已保存赛程使用。 |
| 已取消 | 以页面报告的实际保存状态为准，提交前取消保留原赛程。 |
| 存储失败 | 按[故障处理](troubleshooting.md#保存失败与已保存但无法重读)核对是否提交及可用副本。 |

例如诊断证明某选手一条可能路径需打至少 21 场，而五天每天最多 4 场只容纳 20 场，应增加比赛日或由组织方重新确定规则；单纯增加球场无法解决这个每日场次矛盾。

“本次搜索未找到”与“已证明容量不足”代表不同证据。前者仍可能存在本次搜索未找到的可行排法。核对详情保存失败时的资源快照、相关项目、终止阶段和计算完成情况；之后编辑输入不会改变这份诊断。

优先核实真实资源和预计时长。休息、每日场次及决赛要求由组织方决定；调整这些参数后应重新核对赛事规程。失败不会把部分新赛程发布为完整安排。

## 手动调整、连锁和撤销

从“查看赛程板”进入摘要页，点击“打开独立赛程板 ↗”。独立窗口与主窗口共用当前赛事，默认最大化；可恢复大小、移动到其他屏幕，也可同时使用主窗口。

### 浏览与定位

赛程板按“时间 × 场地”展示整场赛事。顶部工具区可切换比赛日、缩放、紧凑／详细卡片以及撤销。横向滚动时保留时间列，纵向滚动时保留场地标题；卡片用项目颜色和文字区分项目。

当前赛事会话内，关闭再打开窗口保留日期、缩放和显示密度。再次点击打开按钮会激活已有窗口；切换赛事时关闭旧窗口。

点击卡片先查看比赛详情，再点击“调整时间与场地”进入编辑。整分钟显示为 `HH:mm`，原时间含非零秒时保留秒数。选择或定位比赛只改变视图。

### 精确调整与连锁方案

1. 选中待调整比赛，点击“调整时间与场地”。
2. 填写目标比赛日、开始时间和场地。
3. 点击“查看本场调整方案”或“查看连锁调整方案”。
4. 核对每条原位置、新位置和诊断，可用“定位本场”“定位关联比赛”查看。
5. 点击“确认并保存调整”，或“取消调整”保留原赛程。

连锁方案只尝试移动本项目受影响的后继比赛，搜索位置时仍检查整场赛事的场地、裁判和兼项约束。后继已完成、无合法位置或整组变更校验失败时，整组方案均不提交。

“收起 ×”隐藏详情面板并保留已填目标和当前方案；“载入最新位置”重新载入当前已保存位置。预览绑定生成它时的赛事状态，导入赛果、重新读取、恢复、切换赛事或其他修改后，须按提示重新预览。

### 拖动与撤销

未完成卡片可拖到目标时间和场地。悬停时显示目标校验反馈，松开后会按当前状态再次校验；合法时保存，失败则显示原因并保留原位置。需要精确跨日调整时，使用详情面板中的目标比赛日。

“撤销移动”回退当前可撤销的一次手动操作，整次连锁调整作为一次操作。撤销本身也要通过当前赛事校验，不能突破已有赛果锁定或决赛日期要求。保存后主窗口、赛程板和之后导出的材料同步使用新位置。

## 选手兼项与负荷核对

至少两个项目已导入名单时显示“选手兼项”，全部名单就绪后可打开。准备名单阶段即可核对跨项目报名，生成赛程后再查看时间与负荷。窗口可调整大小，主窗口和赛程板均可继续使用。

左侧按姓名或学号搜索，并支持按休息间隔排序。右侧包含报名项目、搭档和单位；有赛程时显示已确定比赛与折叠的“后续可能参加”。报名项目数依据原始报名，选手淘汰后仍保留。

已确定比赛用于统计冲突、休息不足和最短间隔。最短间隔取同一天按开始时间排列的相邻确定比赛；负数表示重叠，没有同日可比较场次时显示暂无并排到休息排序后方。冲突和休息不足按确定比赛对统计，休息检查同时考虑跨午夜的真实日期间隔。

潜在晋级场次独立列示，须结合后续赛果继续检查；它们未进入已确定场次统计。全局排程校验仍会检查相容的潜在路径。

点击“在赛程板中定位”会打开或激活赛程板、切换日期并滚动到目标卡片。“当前定位”标记持续保留，直至选择另一场或“取消定位”。名单、移动、撤销和赛果导入后，窗口自动更新；赛程作废时保留报名信息，收起比赛安排。

发现缺失学号或同一学号对应不同姓名时，回到原始名单核对。兼项视图依赖已输入身份；同名缺学号与身份填写不一致会影响汇总。

## 质量报告

生成成功后，设置页显示每日比赛数、占用分钟、可用分钟及利用率。重新生成时，有可用对比结果还会显示调整位置和跨日场数。

选择多个项目导出现场材料时，生成 `多项目排程检查报告.xlsx`。报告重新检查整场赛事，包含：

| 工作表 | 查看内容 |
| --- | --- |
| 检查总览 | 生成时间、赛事与全局场次、记录进度、检查结论和统计口径。 |
| 当前赛程卡片 | 全部项目的阶段、计划日期、起止时间、场地、双方、赛果状态和实际比赛日期。 |
| 检查明细 | 问题代码、说明、本场与关联场次，便于定位。 |
| 选手每日负荷 | 每名选手的已确定出场数、最大可能出场数及未完成计算说明。 |
| 资源与日负荷 | 每日开放时间、场地、可用容量、占用、利用率和项目时长设置。 |

“已确定出场数”是计划中已能确定参赛者的场次数；“已完成场数”依据已保存赛果。最大可能出场数考虑实际相容的晋级路径。计算未完成时，报告显示已证明范围或“未知”，应保留这个不确定性。

“检查不通过”表示存在硬约束违规；“硬约束检查未完成”表示尚不能判断完整冲突情况。报告是诊断材料，交付时还应核对实际输出完整性、场馆开放、选手身份、裁判安排和打印效果。

## 现场记录与材料不会隐式排程

现场工作分别执行结果导入和材料导出。导入赛果后，后续对阵依据胜负更新，计划时间和场地保持原安排。比赛临时延误或改场时，在赛程板中明确调整未完成场次。

导出可把有效历史记录中仍待赛的比赛补入指定目标日。目标日材料显示“待安排”，原计划保留在说明中。记录日用于整理材料，实际比赛日期用于赛果，计划日期用于赛程；这三者分别记录。

每日赛程 Excel 提供逐场明细、时间场地网格和参数。网格以实际起止时间段分行，同一起止时间的场次同一行，行高按文字量设置。带时间对阵图展示完整项目签表，便于将时间、场地和晋级关系一起核对。

记录表的本表公式、正常与弃权填写、单日与多日材料文件名，以及单场和团体计分表见[比赛现场操作](usage.md#5-比赛现场)。

## 审计与复查材料

公开前建议裁判长逐项核对：

- 名单身份、双打搭档、种子和已确认签表。
- 比赛日、实际预约场地、不可用时段和裁判人数。
- 项目时长、选手休息、每日上限及冠亚军决赛日期。
- 关键晋级场次的前后依赖，兼项选手的实际安排。
- 材料包文件列表、打印页数、记录表公式及现场人员使用方式。

留存原始名单、抽签材料、随机种子、赛事文件、备份和填写后的记录表。赛程检查只覆盖程序中的计划条件，实际开赛延误、队员临时变化和场馆交通由现场组织持续管理。更详细的抽签复核方法见[公平性与公开审计](fairness.md)。
