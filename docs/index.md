# 文档中心

深大羽协 · 赛事助手是一款用于 Windows 和 macOS 的羽毛球赛事工作台，提供名单管理、公开抽签、赛程编排、现场材料、赛果记录和备份恢复。

本目录的使用说明与技术文档按仓库当前程序编写。已发布安装包的功能范围见对应[发布说明](releases/v5.0.1.md)。

## 办赛流程

| 阶段 | 主要操作 | 获得的结果 |
| --- | --- | --- |
| 01 比赛概览 | 核对赛事名称、类型、项目和筹备目标 | 一份承载整场比赛的 `.szbd` 赛事文件 |
| 02 准备名单 | 按项目导入名单，核对姓名、学号、搭档、单位和种子 | 可用于抽签的参赛名单 |
| 03 公开抽签 | 设置分组、随机种子，执行抽签，确认并导出 | 各项目签表及公示材料 |
| 04 安排赛程 | 设置比赛日、时间、场地和约束，生成赛程，通过独立赛程板调整 | 带日期、时间和场地的比赛安排 |
| 05 比赛现场 | 导出比赛材料，检查和导入填写后的记录表，查看比赛进展 | 累计赛果、更新后的对阵及现场材料 |
| 06 完成与归档 | 核对完成情况、导出材料并创建备份 | 可继续打开或交接的赛事资料 |

只负责公开抽签时，创建比赛时选择“先完成公开抽签”，完成确认和公示后保存赛事文件。继续筹备时，可在比赛概览中选择“继续筹备完整赛事”，使用同一份赛事文件。

首页的“最近的比赛”显示最近一次打开或保存的时间，并按最近活动排序。点击“继续”打开对应赛事，鼠标悬停可查看文件路径和详细时间。赛事可通过顶部“更多”切换，备份和恢复集中在顶部“备份与恢复”。

顶部“帮助”提供离线文档阅读、搜索、复制和字号调整。“模板导出”可在创建比赛前使用，提供通用参赛名单 Excel、空白单场比赛计分表和空白团体比赛计分表；两种计分表均支持 Excel 和 PDF，可单独或批量导出。操作步骤见[使用说明](usage.md#帮助与空白模板)。

## 比赛类型

- **团体赛**：以参赛单位为队伍，包含一个团体项目。排程中的一场比赛代表两支队伍的一次团体对抗，统一设置基础时长；现场材料提供分场填写位置。
- **单项赛**：可选择男子单打、女子单打、男子双打、女子双打和混合双打中的一至五项。每个项目有自己的名单、签表和时长，多项目共用比赛日、场地、裁判容量和个人负荷约束。
- **选手兼项**：至少两个项目已导入名单时显示入口，全部项目名单准备好后可打开，查看同一选手参加的项目和搭档；生成赛程后可继续检查其确定场次和休息间隔。

## 常用文件

| 文件 | 内容与用途 |
| --- | --- |
| 赛事文件 `.szbd` | 保存项目、名单、抽签、赛程、赛果、操作记录及恢复信息 |
| 名单 `.xlsx` | 输入报名资料和种子设置 |
| 抽签结果 `.xlsx / .pdf / .png / .jpg` | 公开展示签表；Excel 同时包含名单和抽签审计信息 |
| 赛程安排表 `.xlsx / .pdf` | 查看每日时间与场地分配 |
| 赛程记录表 `.xlsx` | 填写胜方、比分和用时，导入累计赛果；同一天的所选项目集中在一张记录表中 |
| 单场比赛计分表 `.pdf` / 团体比赛计分表 `.xlsx` | 现场执裁和纸面记录 |
| 带时间对阵图 `.xlsx / .pdf` | 按项目查看签表中的比赛时间、场地和晋级来源 |
| 材料包说明 `.txt` | 核对项目、日期、材料范围和文件清单 |

材料按实际选择的项目数量命名。选择一个项目时，文件夹和每日文件带项目名称；选择多个项目时，使用“多项目合并材料包”和“合并”文件名。具体示例、记录表公式和填写步骤见[使用说明](usage.md)。
