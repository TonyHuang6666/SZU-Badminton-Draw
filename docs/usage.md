# 5.0 使用说明

本文面向 5.0 开发候选的赛事助手式界面。5.0 尚未正式发布；2026-10-03 的本地构建、回归及 macOS 代表页面检查范围见 [GUI 验证报告](acceptance/v5-gui-2026-10-03.md)，该报告不代表此后赛程窗口改动已完成验证。发布与平台状态见[文档中心](index.md)。5.0 不提供 4.x 存档导入或迁移，也不再使用多个项目存档先排后合的流程。

## 使用前先做三个决定

| 问题 | 选择 | 影响 |
| --- | --- | --- |
| 办团体赛还是单项赛？ | 二选一 | 两者不能在同一赛事文件中混排。 |
| 单项赛有几个项目？ | 一至五项 | 单项目、多项目都统一尽快安排；可选将各项目冠亚军决赛固定在最后比赛日。 |
| 这次只做什么？ | 先完成公开抽签 / 从抽签到现场，筹备整场比赛 | 只做抽签可以确认、导出后停止；以后可继续筹备，但不会自动排程。 |

推荐先用 [`samples/v5`](../samples/v5/) 的虚拟名单完整练习一次，再处理真实报名数据。正式办赛前准备：

- 已核对的报名名单及学号；
- 组织方确定的种子与赛制；
- 公开抽签使用的随机数种子；
- 完整赛事需要的比赛日期、开放时间、场地、不可用时段和裁判容量；
- 一个明确的赛事文件保存位置，以及独立的材料输出目录；
- 真实赛事文件和原始名单的额外备份。

打开赛事后，左侧显示六步进度：

| 步骤 | 在这里做什么 |
| --- | --- |
| 1 比赛概览 | 查看筹备进度、比赛信息和下一步。 |
| 2 准备名单 | 导入各项目名单，核对提醒和种子。 |
| 3 公开抽签 | 开始公开抽签，检查待确认的抽签结果，再确认或导出。 |
| 4 安排赛程 | 设置资源、生成赛程，并进入赛程板查看或调整。 |
| 5 比赛现场 | 先导出材料，再导入结果、查看比赛进展。 |
| 6 完成与归档 | 检查完成情况、导出交接材料并留存备份。 |

当前步骤会突出显示，已完成步骤可以回看；尚不能进入时，旁边说明还缺少什么。赛程板属于第 4 步，不是另一条独立主流程。页面底部提供当前步骤的操作或下一步入口。

首页和新建比赛页面会隐藏先前比赛的标题、进度栏及文件路径，避免把新比赛与旧文件混淆。顶部“更多”可返回首页、打开其他比赛或重新读取文件；“明暗切换”切换浅色和深色外观。常用设置直接显示，其余选项放在可展开区域；折叠设置不会清空内容。需要处理的检查结果和确认操作仍应逐项核对。操作出错或文件打不开时先看[故障处理](troubleshooting.md)，不要急着覆盖原文件。

## 1. 创建比赛与比赛概览

在首页点击“创建一场新比赛”。向导分为比赛信息、参赛项目、保存比赛三步，依次收集名称、类型和工作目标，项目及赛制，最后核对摘要和 `.szbd` 保存位置。

- 团体赛：只有一个团体项目。
- 单项赛：从男单、女单、男双、女双、混双中选择一至五项，每种项目只能出现一次。
- 先完成公开抽签：完成名单、抽签和公示即可停下，不要求输入任何赛程资源。
- 从抽签到现场，筹备整场比赛：允许以后进入统一排程和现场执行，但仍必须主动完成抽签、确认等步骤。

团体赛与单项赛不能放在同一工作区里同时编排。不要通过把团体名称写成单项项目来绕过此限制。

赛事文件在抽签前就创建。每个成功命令会自动保存，不存在最后再点击一次“创建赛事存档”的步骤。比赛概览汇总名单与抽签进度，并给出下一步入口；“编辑比赛信息”仍受当前赛事状态限制。

回到首页可以点击“打开已有比赛”，或在最近的比赛中点击“继续”。找不到最近文件时，请重新选择正确位置；条目上的“×”只从最近列表移除入口，不删除本地赛事文件。最近文件列表不是备份。

## 2. 准备名单和种子

“准备名单”按项目显示已导入人数或组合数、检查提醒和种子状态。选择项目，导出名单模板后填写并导入 `.xlsx`。按选定项目解释名单，不根据内容偷偷切换成另一种比赛。

点击“导出名单模板…”后直接选择保存位置，无须提前勾选覆盖选项。若选择已有同名文件，系统保存窗口会询问是否替换；不想替换时可返回修改文件名，或取消导出。即使确认替换，程序也不会覆盖名单来源文件、赛事存档或备份。

模板字段依次为姓名、学号、学院/学部、搭档姓名、搭档学号、搭档学院/学部、是否种子、种子序号、备注。删除模板示例，再填写正式报名数据；团体名单在学院/学部列填写队伍名称。单打一个参赛方是一名选手，双打是一对选手，团体是一个队伍；显示数量分别使用人、对、队。

学号是兼项识别的重要依据。相同学号跨项目应对应同一位选手；同名不同人应填写不同学号，双打两人分别填写。同一项目中同一选手不能重复报名或属于两对搭档。无学号时只能按姓名识别，遇到同名歧义必须先澄清；不要依赖程序猜测。

导入后核对警告和种子设置；“名单来源”中显示“导入的文件”及原文件哈希，供核对来源。取消种子时同时清空种子序号；保留旧序号会提示冲突，不能以模糊状态保存。种子由组织方确定，程序不评价运动水平。

点击“设置种子”后，平时只显示“保存种子设置”和“取消编辑”；取消会放弃未保存的种子修改并退出编辑。若编辑期间程序检测到名单或项目设置已变化，会暂停保存并显示原因，以及“重新载入名单后编辑”按钮。该按钮放弃当前草稿，按当前已载入的比赛资料重填名单并继续编辑，不会自动保存，也不会重新导入原 Excel 文件。

种子编辑尚未结束时，右下角会显示“先处理种子编辑”，并说明哪个项目需要保存或取消。点击该按钮、侧边栏、返回首页、新建或打开其他比赛，都不会直接丢弃编辑内容；程序会留在名单页并选中需要处理的项目。多个项目同时处于编辑状态时，须分别保存或取消；保存失败仍保留输入并阻止离页。结束编辑后再点击下一步，只会进入公开抽签页，不会自动抽签。即使刚进入编辑、尚未改值，也请先保存或取消以结束编辑。

全部项目名单有效后，才能进入公开抽签。名单导入不会生成抽签、比赛关系图或赛程。

## 3. 公开抽签与公示

页面将抽签前检查、公开抽签和结果确认分开呈现。适合在线视频会议共享屏幕的流程：

1. 逐项展示已核对名单、种子、赛制和分组数，公开确定随机数种子。
2. 明确点击“开始公开抽签”。这会执行抽签并保存“抽签结果（待确认）”，尚未确认。
3. 检查分组、首轮赛、轮空、出线目标及名次加赛；需要时导出待确认的抽签结果供参会者核对。
4. 确认无误后，单独确认此项目抽签，再导出正式抽签材料。
5. 多项目逐项完成。导出设置中可选择当前项目；只有全部项目都已抽签且同为待确认或同为已确认时，才能选择全部项目。

页面底部保留“继续安排比赛时间”。还有项目未确认时，按钮暂不可用，旁边只显示“还有 N 项未确认 · 查看”。点击“查看”才会向上弹出清单，列出“未抽签”或“待确认”的项目，不占用正文空间。点击项目按钮后清单自动收起，切换并回到该项目的检查区域，不会自动抽签、确认或保存；按 Esc 或点击清单外可关闭。全部项目确认后提醒自动消失：完整筹备赛事以“继续安排比赛时间”为主要操作，只做公开抽签的赛事以导出为主要操作。进入赛程只要求全部抽签确认，无须先导出文件。

页面底部只有“导出抽签结果…”一个导出入口。点击后在设置窗口中选择范围和格式：当前项目显示具体名称，多项目另显示“全部项目（N 项）”；单项目不重复提供全部项目。全部确认的多项目赛事默认全部项目，否则默认当前项目；格式和分页可沿用上次接受的设置。全部项目尚未抽签完成或确认状态混合时，不能选择全部项目。

导出可以选择 Excel、A4 PDF、PNG、JPEG 或全部格式。选中包含 PDF 的格式时显示“PDF 分页设置”，可按需展开，拼页行列须为正整数。已抽签但未确认也可导出，材料保留“抽签结果（待确认）”标识，文件名包含“待确认抽签结果”；确认后的材料标明“抽签结果（已确认）”。导出不会自动确认抽签或转入排程。

点击设置窗口中的“选择导出文件夹…”后，系统打开文件夹选择器。没有同名文件就直接导出；有同名文件时，程序列出本次将替换的具体文件，点击“替换这些文件”才继续。取消设置不会导出、保存存档或改变上次设置；取消文件夹选择或替换确认不会覆盖原文件。无须提前勾选覆盖选项，每次导出单独确认。设置、选目录或确认期间切换项目、赛事或离开页面后，原请求失效，须重新发起导出。

编辑框里的新设置不会自动替代已保存的抽签结果。若要按新设置抽签，请点击“按当前设置重新抽签”；这会实际重新抽签并保存，替换本项目待确认的抽签结果。导出仍以已保存的抽签结果为准。程序显示的随机种子、输入哈希、算法版本、生成与确认时间，应随材料一起留档。

团体或单项淘汰赛可以只让每组产生一个出线者；二的幂次分组可选择继续决出总冠军，单组直接决出冠军。名次加赛只在相应冠军赛制下启用。循环赛生成组内全部对阵，最终小组排名仍需裁判长按赛事规程判定。

公开抽签确认并导出后，可以直接关闭程序，也可以到“完成与归档”留存备份。以后打开同一赛事文件会保留已确认签表，不需要重新抽签。只有主动点击“继续安排比赛时间”，才会继续到排程设置；只做公开抽签的赛事会在此时转为完整筹备，转换本身不会生成赛程。比赛概览也保留“继续筹备完整赛事”入口。

已确认抽签为只读。“抽签记录与更正”保留原始记录和解除确认入口。如果尚无任何赛果，可以填写原因并确认解除某项目的抽签确认；这会作废该项目比赛关系图和整场全局赛程，需要重新检查、确认和排程。已有赛果后不允许用此入口重抽。

## 4. 安排赛程

全部抽签确认后，完整赛事才能进入排程设置。首先填写共同的比赛日期、每天开始和结束时间、可用场地，以及各项目的预计单场时长。页面显示预计比赛数量、所需时间与可用容量；估算不代表所有冲突都能排开，实际生成仍会执行完整校验。

点击“比赛日期”或旁边的日历图标选择日期，不再手动输入。日历箭头切换月份，点击顶部年月可选择月份或年份；点选某一天后自动收起。也可用 Tab 聚焦日期框、按空格或 Enter 打开，按 Esc 取消。选日期只修改当前草稿，不改变已填时间、场地及其他设置，仍须点击“检查并生成赛程”才保存。

点击“添加比赛日”后，新卡片放在列表最上方，页面自动显示添加按钮和新卡片，方便连续添加。默认日期取已有有效日期中最晚一天的次日；修改日期时卡片不会跳动。重新打开或载入已保存设置时，卡片按日期由晚到早显示，实际排程和导出仍按日期先后处理；“沿用上一比赛日的场地…”仍指日期上最接近的前一个比赛日。

“每天开始”和“每天结束”也通过点选设置：点击时间框，选择小时与分钟，再点击“确认”。采用 24 小时制，小时为 00–23，分钟为 00–59；点击“取消”、按 Esc 或点击弹窗外会保留原值。结束时间必须晚于开始时间，否则生成时会提示重新选择，不会修改已保存的赛事。时间选择只修改当前草稿，仍须点击“检查并生成赛程”才保存。高级设置中的不可用时段和裁判时段暂时仍手动填写。

时间框统一显示为“09:00”“18:00”等完整时间，字体、留白和边框与其他输入框保持一致。点击时间文字、右侧钟表图标或框内空白，都可打开原有的小时／分钟选择器；显示样式不改变确认、取消或保存规则。

点击每个比赛日的“选择场馆与场地…”打开选择窗口。内置粤海校区运动广场东馆羽毛球场（A1–A8、B1–B8、C1–C8、D1–D8，共 32 片），以及丽湖校区至快体育馆（1–12 号场）、至畅体育馆（1–10 号场）。东馆可按 A、B、C、D 区选择，其他场馆按数字顺序勾选；也可全选或清空。内置清单不是预约证明，新比赛日不会自动选择任何场地，请只选择实际已预约或确认可用的场地。

校外用户选择“自定义场馆”，填写场馆名称与场地名称。场地可每行一个，也接受中英文逗号、分号；输入数量可生成 1 号场至 N 号场（最多 256 片），已有内容时按钮会明确提示替换。场馆名留空可保留原有场地名称；已有赛事的 B1、B2 等自由名称不会被猜测成深大场馆或自动改名。

主页面只显示场馆和所选场地摘要。“沿用上一比赛日的场地…”会带入日期早于当前日、且最接近当前日的场地选择，检查并确认后应用；不会复制不可用时段或修改日期、时间。取消、关闭选择窗口不改变草稿。修改设置、重新载入、切换赛事或离开页面后，先前尚未完成的选择不再应用。

不可用时段通过“选择不可用场地…”从当天已选场地中勾选。“当天全部场地”表示全场暂停，不等同于未勾选任何场地。更换场馆或减少场地如影响已有不可用时段，窗口会列出影响并要求明确确认：保留时段中仍被选用的场地；若没有剩余场地则删除该时段，不把它变成全场暂停。原本选择“当天全部场地”的时段仍作用于新选场地。

内置场地以“粤海东馆 · A1”“丽湖至快 · 1号场”“丽湖至畅 · 1号场”等名称保存和导出，避免不同馆同号场地混淆；每日赛程 Excel 的赛程参数中补充实际使用的内置场馆全名。选择窗口只修改排程草稿，仍须点击“检查并生成赛程”才保存。此版只提供场馆选择便利，尚未实现分校区预选、集中阶段场馆约束或跨校区交通时间校验，不能据此认定同时启用不同校区即可安全排程。

单项目和多项目都默认尽快安排，不需要选择排程策略。多个项目共享时间、场地和参赛人员，由程序一起安排，不会分别排好后互相覆盖。

如需集中举行决赛，勾选“将各项目决赛安排在最后一个比赛日”。这里的决赛仅指冠亚军决赛；最后一天指所填日期中最晚的一天，页面会显示该日期。勾选后必须满足，不能因场地紧张自动改到前一天；半决赛、季军赛和排位赛仍尽早安排。只有一天时自然满足；没有冠亚军决赛的项目不受影响。未勾选时，决赛也按默认方式尽早安排。

“高级排程设置”保留不可用场地时段、裁判并发容量与分时人数、最小休息、每日场次上限和分段时长；不再需要填写负载百分比、累计阶段进度或选择各轮日期偏好。折叠区域只收起显示，不停用或清空仍保留的设置。

修改日期或勾选项只编辑草稿，不会即时重排。点击“检查并生成赛程”后才尝试排程、完整校验并保存；失败会保留之前的合法工作区和赛程，列出未安排场次、约束及建议。打开旧存档不会自动改变原赛程；再次生成时不再沿用已移除的软目标。已有赛果后不能重新生成整场赛程，只能调整未完成场次。保存了决赛末日要求后，手动调整和连锁移动也不能把决赛移到更早日期。

不想保留本页刚改的设置时，点击“放弃未保存的修改”，再选择“放弃修改”。程序会恢复已保存的日期、时间、场地、时长和高级设置，不改变现有赛程；没有已保存的设置时则恢复程序初始设置。未改动或已把数值改回原值时，按钮不可用。选择“继续编辑”、按 Esc、在默认焦点下按回车或关闭确认窗口，都保留当前输入。若提示旧草稿与当前赛事冲突，也通过此按钮恢复最新已保存的设置。

详细资源填写、硬约束与偏好的区别见[赛程编排说明](scheduling.md)。默认值是产品初始设置，不是正式赛事规则认证。

### 查看和调整赛程板

生成赛程后，从“查看赛程板”进入。主窗口先显示赛程摘要，并提供打开赛程板、返回排程设置和前往比赛材料的入口。赛程板在独立窗口中打开，默认最大化，可还原、调整大小，并与主窗口同时使用。重复打开会激活已有窗口；关闭赛程窗口不会关闭当前赛事。在当前赛事会话内关闭后重开，会保留所选日期、缩放和紧凑／详细显示选择；切换赛事时关闭旧赛程窗口，避免混淆比赛资料。

赛程板以“时间 × 场地”展示整场赛事，顶部集中提供比赛日、缩放、紧凑／详细显示和撤销操作。横向浏览时保留左侧时间列，纵向浏览时保留顶部场地标题。默认紧凑卡片以项目颜色辅助区分，并保留项目文字标签和比赛信息；需要更多信息时切换详细显示。整分钟时间显示为“09:00”，原值含非零秒时保留秒数，不因简化显示改变比赛时间。

点击卡片先选中并查看比赛信息；需要修改时，再点击“调整时间与场地”展开调整选项。收起浮层可继续浏览全部场地。赛程窗口内显示操作状态和错误，主窗口与赛程窗口使用同一份当前赛事数据。普通拖动在松开后重新校验，合法时自动保存；悬停反馈本身不代表已经保存。

在右侧面板中选择比赛、目标日期、开始时间和场地，点击“查看本场调整方案”或“查看连锁调整方案”，检查每条原位置和新位置，再确认保存全部变更。查看方案和“取消调整”都保留原赛程；只有确认并保存才提交方案。点击“在赛程板中定位”“定位本场”或“定位关联比赛”会收起遮挡面板并定位目标；收起面板会保留已填写的目标和当前调整方案，不等于取消调整。连锁移动只自动调整本项目受影响的后续比赛，但必须通过全赛事资源、兼项和休息校验。无法安放整个变更集时，不保存其中一部分。

已完成比赛不能移动。撤销上次移动也是受当前状态校验的保存操作，不是无限历史回退；切换工作区、重新载入、赛果导入等改变状态后，旧调整方案和旧撤销资格可能失效，需要重新核对。

### 查看选手兼项

“安排赛程”主页面的“选手兼项”与“查看赛程板”并列，赛程摘要页也提供同级入口；生成赛程后即可直接打开，无须先进入赛程板。独立、可调整大小的双栏窗口不阻挡主窗口和赛程板。左侧按报名身份汇总跨项目选手及项目数，支持按休息间隔从短到长或从长到短排序；右侧显示所选选手的比赛日期、时间、场地、搭档／对手、完成状态及冲突提醒。点击“在赛程板中定位”会打开或激活赛程板并定位对应比赛，不修改赛程，也不清空排程设置草稿。两个窗口可以分别关闭；切换赛事或关闭主窗口时会关闭旧窗口。

移动、撤销、重新生成赛程或导入赛果后，明细自动更新，并尽量保留选手和排序选择。报名项目数不因选手已被淘汰而减少；双打两名选手分别识别。身份依据与名单相同：优先使用学号，无学号时按姓名匹配。

“已确定参加的比赛”和折叠的“后续可能参加”分开展示。尚未决出的胜者／败者只列为可能参加，不计入已确定场次、最短间隔或已确定比赛的风险数；不能把尚未确定理解为没有风险。最短排定间隔取同一天、按开始时间排列的相邻确定比赛，负数表示重叠；无同日可比较场次显示暂无，并在两种休息排序中置后。冲突及休息不足按确定比赛对计数，休息检查也覆盖跨午夜的实际日期间隔。这些是计划赛程检查，不是选手实际完成比赛后的休息计时。

## 5. 比赛现场

页面按“1 导出比赛材料 → 2 记录比赛结果 → 3 查看比赛进展”排列，默认打开材料页。三个页签之间切换不会提交操作，也不会代替检查和确认。

导出、导入的核对说明与确认勾选放在相应内容中，随页面滚动；底部仅保留紧凑的短状态与操作按钮。导入确认仅在已有当前检查结果时出现。原有范围确认、更正许可和更正原因仍须满足；“查看比赛进展”只读，不要求写入确认。

### 先导出现场材料

先明确勾选材料日期并选择保存文件夹。默认范围为全部项目；如需只导出某个项目，在“高级导出设置”中选择。这里还保留跨日待填记录和 PDF 分页设置。若要将以前记录过但尚无赛果的场次带入某天材料，需另外启用补入较早待填记录并指定目标日；默认不启用，也不会自动找“下一日”。

页面会汇总当前范围。核对项目、日期、PDF 分页与保存文件夹，勾选确认后点击“生成现场比赛材料”。有同名文件时，会列出本次需要替换的具体文件，单独询问是否替换；取消不会生成文件或保存导出记录，原文件保持不变。改变来源、范围、目录或拼页设置会撤销原来的确认。空日期范围不是“全部日期”。

选定的保存文件夹作为上级目录，程序在其中生成按所选日期命名的材料包，例如 `9月20日-9月22日多项目合并材料包`；只选一个项目时为 `9月20日-9月22日男子单打比赛材料包`。单日使用一个日期，即使部分选定日期没有场次，目录日期范围仍保留本次选择。再次导出同一范围使用相同目录，并继续按具体文件确认替换。同名或文件名清理后重名的项目使用 `（2）`、`（3）` 区分；只选其中一个项目也保留其编号。

历史导出文件不会自动清理，包括旧版本生成的分项目记录表；需要干净材料包时请选择新的保存文件夹。

材料按实际内容生成：

- 每个选定项目的完整带时间场地对阵 Excel 与 A4 PDF，如 `男子单打带时间对阵图.xlsx`；日期筛选不裁断项目签表。
- 每个非空材料日只有一份合并赛程记录 Excel，如 `9月20日合并赛程记录表.xlsx`，包含当天所选项目的全部场次，按比赛时间、已配置场地顺序排列；不另生成分项目记录表。
- 非空材料日的合并赛程安排 Excel 与 PDF、合并单场比赛计分 PDF 或合并团体比赛计分 Excel。每日文件名带日期，如 `9月20日合并赛程安排表.xlsx` 和 `9月20日合并赛程安排表.pdf`。
- 全赛事排程检查 Excel，以及材料包说明和校验清单。全部项目范围使用 `多项目排程检查报告.xlsx`、`合并材料包说明.txt`；单项目范围使用 `赛程检查报告.xlsx`、`比赛材料包说明.txt`。即使只导出一个项目，质量检查仍覆盖整场赛事。

每日赛程以起止时间段为行、场地为列，同一起止时间的比赛放在同一行；底色区分比赛阶段，空档保持空白。行高用于容纳文字，不代表比赛时长；Excel 同时保留赛程明细。记录表保留打印标题、示例行和晋级来源公式。同一张记录表中包含前置场次时，填写其胜方后，后续场次对阵会通过公式更新；前置场次未包含在本表时，显示导出时已有的对阵或来源说明，不跨文件读取赛果。

记录表的 A–M 列沿用 4.6 主表布局，包括“对阵数据”合并表头、列宽、行高和阶段底色，默认只打印这一区域。N–T 列是隐藏的导入标识与胜方选项，不要删改；右侧 U–V 列“结果类型、实际比赛日期”用于 5.0 赛果导入，在电子表格中填写，不纳入默认打印区域。

待赛顺延只改变本次材料呈现：记录日是目标日，原计划日期保留，时间和场地显示“待安排”，未知实际比赛日保持空白。它不移动存档内赛程，不补写赛果，也不等于已完成。实际调整仍在赛程板操作。

成功后页面显示实际材料包目录和文件名；技术详情可展开查看实际范围、跳过项、文件路径、字节数和哈希。未确认的同名文件不会被覆盖；检查后新出现的冲突会阻止对应文件发布，名单来源、赛事存档、备份、符号链接与目录保护仍然有效。发生部分发布或审计保存失败时，核对技术详情中的已发布文件、尝试发布路径及保留的暂存目录；正在尝试但状态未知的路径不能算已验证成功。不要直接把残缺目录交给工作人员当作完整材料包。

打印前预览：复杂对阵图增加拼页可能切开连接线；宽记录表文字可能较小；团体计分表按整组子场版式分页；质量表可能使用 A3。实际纸张、打印机及系统字体差异需现场检查。

### 填写和导入记录表

保留程序导出的记录表原件，另存一份用于填写。在真实比赛行中填写比分、用时、胜方、赛果类型和实际比赛日；不要填写示例行，不要删改隐藏 ID、签表版本、确认时间、记录日、原计划信息或对阵来源公式。

- 胜方优先使用表内下拉选项，也支持明确的 `A` / `B`，不靠姓名中的“胜者”“负者”等字样猜测。
- 比分方向始终是 A 对 B，例如 `21-10`；多局用 `21-10, 18-21, 21-17`。程序检查可识别格式、方向和局数，不认证所有赛事的计分规程。
- 正常赛果必须有有效比分和正整数分钟用时。弃权赛果使用明确类型、胜方与零分钟；不要把缺失比分的正常比赛冒充弃权。
- 待赛行的实际比赛日可留空表示未知；有胜方的赛果必须明确填写实际比赛日，弃权也不例外，日期必须已在工作区资源中配置。它与原计划日、材料记录日是不同字段。
- 不填胜方的合法空白行表示待赛；错误格式、冲突身份或有问题的填写不会自动当作安全待赛跳过。

在“记录比赛结果”页签点击“选择比赛记录表”，可以一次选择多份、多个日期的文件。点击“检查记录表”后，逐项核对文件哈希、工作表、行号、记录日、诊断和增加/重复/待赛/更正计数；完整文件来源与分类可展开查看。阻断诊断直接显示，需要更正时会显示前后值、允许更正选项和原因输入。勾选确认后才导入，选择文件、清空列表或修改确认条件不会自动提交。

同一文件内容重复导入不会重复写入赛果。已导入的合法待赛文件可能只有覆盖凭据、没有新增赛果，因此“已覆盖的记录行”和“已完成比赛数”不是同一个数。历史区域同时保留有效和已作废凭据，不能把作废历史当当前待赛来源。

胜负方不同属于阻断冲突，不允许用普通更正覆盖。比分、时长、类型或实际日期等允许的元数据更正，须启用更正、填写原因并重新检查记录表并确认；更正前后值及来源会留在历史中。旧文件重导不会反转已经发生的更正。

### 查看比赛进展与更新材料

导入成功后，下游对阵按存档赛果解析。“查看比赛进展”显示各项目已记录场次和当前赛果，点击“查看赛程与后续对阵”可回到赛程板。导入回执、更正历史和原始操作记录仍可展开查看。程序不会在后台自动导出新材料；核对后再独立选择材料范围。全部真实比赛均有有效赛果后，赛事才成为“已完成”；导出文件或导入待赛表不会使赛事完成。

## 6. 完成与归档

全部项目抽签确认后即可查看此页。它汇总各项目进度、尚未填写的结果和最近手动备份记录。完整赛事尚未结束时，会明确显示待记录场次；这里没有强行把赛事标记为完成的操作。

只做公开抽签时，可以回到抽签页导出正式公示材料，再留存赛事备份。完整赛事的“前往导出最终材料”返回比赛现场材料页；已有赛程才可导出。全部赛果记录完成后，再生成用于交接的最终版本。

“创建赛事备份”打开备份与恢复面板，再点击“创建当前比赛的备份”。备份保留当前进度，不会改变比赛完成状态，也不会自动同步后续修改。建议同时保留原始名单、抽签公示、填写后的记录表和最终材料。

## 7. 备份、恢复和错误处理

备份入口属于整个程序，不要求先进入比赛现场。顶部“备份与恢复”和首页“恢复以前的比赛”都可打开同一面板。正常赛事文件可以主动创建手动备份；记录提示中的已验证副本路径、赛事 ID、修订和哈希。自动备份与手动副本各有用途，创建出一个文件不代表它已经通过完整性检查或对应审计已保存。

恢复正常赛事文件时，目标是当前打开的比赛。选择同一赛事的备份，点击“检查备份与恢复范围”，核对完整目标路径、备份身份和保存进度，再填写原因、勾选确认并点击“确认恢复并保存”。检查本身不替换文件。恢复会保留目标原状态副本并写入恢复审计，修订继续向前，不能把旧备份检查结果带到恢复后的状态继续提交。

无法打开损坏赛事文件时，仍可进入备份与恢复，勾选“赛事文件已经损坏、无法打开”，明确选择损坏目标及备份。此时程序无法从损坏文件证明原赛事身份，必须人工核对路径和备份摘要。检查后任一来源字节变化，都需要重新检查；更换比赛、来源或关闭面板后，原确认也不会继续生效。

如果提示“已保存但无法重读”，不要把它当成未保存并反复重试；重新载入工作区，核对持久化状态后继续。未提交、候选文件、未验证副本、已提交但重读失败会分别报告，不保证每个失败留下的文件都是可恢复备份。

底部状态先提示可采取的下一步，“操作详情与赛事文件”保留原始信息和路径；比赛现场与恢复面板也保留本次操作的实际结果。发生部分保存或材料导出失败时，应同时核对这些证据，不能只凭一个文件存在就判断整次操作成功。

更完整的现象—处置对照、版本不兼容和提交问题时应保留的信息见[5.0 故障处理](troubleshooting.md)。抽签复核和建议留档见[公平性与公开审计](fairness.md)。
