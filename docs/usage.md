# 使用说明

本页按办赛顺序介绍名单、公开抽签、赛程、现场记录和归档。排程资源与调整方法见[赛程编排说明](scheduling.md)，操作失败时见[故障处理](troubleshooting.md)。首次使用可先用 [samples/v5](../samples/v5/) 中的虚拟名单练习。

一场比赛保存在一个 `.szbd` 赛事文件中，包含全部项目的名单、签表、赛程、赛果和操作记录。成功的操作会自动保存；输入框中尚未提交的设置仍是草稿。建议为赛事文件、原始报名表和导出材料分别准备清晰的目录，并在抽签确认、赛程确定和每日赛果导入后创建备份。

打开比赛后，左侧按六步显示进度：

| 步骤 | 主要工作 |
| --- | --- |
| 1 比赛概览 | 核对比赛信息和筹备进度，进入下一步。 |
| 2 准备名单 | 按项目导入报名表，核对身份和种子。 |
| 3 公开抽签 | 执行抽签、展示结果、逐项确认并导出公示材料。 |
| 4 安排赛程 | 设置比赛日和资源，生成赛程，在赛程板中查看、调整。 |
| 5 比赛现场 | 导出现场材料，检查并导入记录表，查看比赛进展。 |
| 6 完成与归档 | 检查完成情况，导出最终材料并备份。 |

顶部“更多”中可返回首页、打开已有比赛或“重新读取赛事文件”；“明暗切换”切换外观。“备份与恢复”在首页和赛事页面均可使用。底部状态栏提示本次操作结果，“操作详情与赛事文件”保留完整说明和路径。

### 帮助与空白模板

顶部“帮助”打开独立阅读窗口，默认显示“程序介绍”，内容为随程序打包的 README，包含功能概览、项目起源与自主研发背景。左侧目录分为“程序介绍”“使用帮助”“技术参考”，可离线阅读并搜索全部文档内容；阅读区支持跨段落拖选、右键复制和字号调整，外观随程序明暗设置切换。选中文字后按 macOS 的 Command+C 或 Windows 的 Ctrl+C 复制，段落换行、列表顺序和链接文字会一起保留；Command+A 或 Ctrl+A 可全选当前文档。文档之间的链接在窗口内跳转，外部网页通过系统浏览器打开。

顶部“模板导出”提供以下三类空白文件，无须创建或打开比赛：

| 模板 | 格式与用途 |
| --- | --- |
| 参赛名单 | 一个通用 Excel，适用于单打、双打和团体名单。第一张表用于填写报名资料，第二张表说明填写方法。 |
| 空白单场比赛计分表 | Excel、PDF，沿用正式单场计分表的版式，比赛信息和选手位置留空。 |
| 空白团体比赛计分表 | Excel、PDF，保留队伍信息、分场记录和比赛结果填写区域。 |

勾选需要的模板和计分表格式，点击导出后通过系统窗口选择保存文件夹。可单独导出，也可批量导出；遇到同名文件时，程序会先询问是否替换。空白计分表用于填写和打印；赛果录入使用“比赛现场”导出的正式赛程记录表。

## 1. 创建比赛与比赛概览

在首页点击“创建一场新比赛”，按向导填写比赛信息、参赛项目和保存位置，最后点击“创建比赛”。

| 设置 | 填写方式 |
| --- | --- |
| 比赛名称 | 使用便于公示和归档的名称，例如“校长杯羽毛球赛”。 |
| 比赛类型 | 团体赛含一个团体项目；单项赛可选男单、女单、男双、女双、混双中的 1–5 项，每种项目各一次。 |
| 本次先做什么？ | “先完成公开抽签”适合先发布签表；“从抽签到现场，筹备整场比赛”用于排程和现场赛果管理。 |
| 比赛方式 | 各项目分别选择淘汰赛或循环赛。 |
| 赛事文件的保存位置 | 选择本地 `.szbd` 文件路径。 |

团体赛和单项赛各自建立赛事文件。一个单项赛事中的多个项目共享同一份赛程资源，并统一检查兼项选手。

“比赛概览”汇总各项目名单、抽签和赛程进度。“编辑比赛信息”是否可用取决于当前比赛状态。只做抽签的比赛可在确认签表后结束本次工作；以后打开同一文件，点击“继续筹备完整赛事”或抽签页的“继续安排比赛时间”，即可保留签表并进入赛程设置。

继续已有比赛时，点击首页“打开已有比赛”，或最近比赛条目中的“继续”。条目显示最近一次打开或保存的时间，悬停可查看详细信息。最近列表保存文件路径；条目上的“×”只移除入口，赛事文件仍保留在原位置。

## 2. 准备名单和种子

### 填写名单模板

可在顶部“模板导出”中取得通用空白参赛名单。进入“准备名单”后，也可选择项目并点击“导出名单模板…”取得带示例的名单。填写后导入 `.xlsx` 文件，程序按当前选择的项目解释名单。

程序读取第一个工作表，以第一个有内容的行为表头。保留模板表头；若使用带示例的名单，先删除示例报名行，再填写真实数据。学号使用文本格式，以保留前导零。

| 列名 | 填写内容 |
| --- | --- |
| 姓名 | 单打选手或双打第一名选手姓名。 |
| 学号 | 第一名选手的身份依据，建议填写。 |
| 学院/学部 | 单项赛选手所属单位；团体赛填写队伍名称。 |
| 搭档姓名 | 双打第二名选手姓名。 |
| 搭档学号 | 双打第二名选手的身份依据，建议填写。 |
| 搭档学院/学部 | 双打第二名选手所属单位。 |
| 是否种子 | 填“是”或“否”；普通参赛方可留空。 |
| 种子序号 | 可选的正整数编号，例如 1、2、3、4。 |
| 备注 | 可选，随原始名单留存。 |

单打每行一人，至少填写姓名；双打每行一对，填写双方姓名；团体每行一队，在“学院/学部”填写队名即可。导入也识别“搭档”“队伍”“学生证号”等常见列名，使用模板列名最便于检查。

例如，男双的一行可填写“张三、20260001、计算机学院、李四、20260002、管理学院、是、1”；团体的一行可只在 C 列填写“计算机学院队”，并按需要填写种子和备注。

### 核对身份与导入提醒

导入后逐项检查人数、姓名、搭档、单位和种子。“名单来源”显示导入文件及其哈希，可用于核对原始文件。

程序优先按学号识别选手，缺少学号时按姓名识别。跨项目的同一选手应填写相同学号；同名不同人应填写不同学号；双打双方各填自己的学号。一个项目内，同一选手只能有一条报名身份，双打选手也只能属于一对组合。学院/学部用于单位信息和抽签回避。

同名、缺失种子编号等情况会显示提醒。请对照原表核实，同名无学号可能被合并，同一人在部分项目缺少学号也可能被拆成两个身份。姓名、学号或搭档有误时，修改原 Excel 后替换名单；名单页的在线编辑用于种子设置。

### 设置种子

组织方在抽签前确定种子。程序按参赛方数量检查种子数量、编号和签位保护：

| 参赛方数量 | 最多种子数 |
| --- | --- |
| 1–15 | 2，且不超过实际参赛方数 |
| 16–31 | 4 |
| 32–63 | 8 |
| 64–128 | 16 |
| 129 及以上 | 32 |

这里的参赛方分别按单打人数、双打组合数、团体队伍数计算。种子序号须为正整数、互不重复，并处于允许的种子数量范围内。填写编号即表示种子；若同时把“是否种子”填为“否”，导入会要求修正。种子可暂不编号，但应在公开抽签前核对提醒。

点击“设置种子”，逐行设置后点击“保存种子设置”；取消种子时同时清空编号。“取消编辑”放弃本次草稿。保存种子会清除本项目原有的待确认抽签结果，随后应重新抽签。

种子编辑期间离开名单页，程序会提示“先处理种子编辑”并定位相关项目。请分别保存或取消各项目的编辑。若提示名单或项目已变化，点击“重新载入名单后编辑”可丢弃草稿并载入当前赛事中的名单，然后重新编辑。

全部项目名单有效后，可进入公开抽签。已确认签表的项目要修改名单或种子，先按下一节的更正流程解除确认。

## 3. 公开抽签与公示

### 设置分组与赛制目标

选择项目，核对人数、种子和“分成几个组？”。循环赛生成每组内部的全部两两对阵，小组最终排名由裁判长依据赛事规程判定。

淘汰赛的分组和目标按以下方式使用：

- 一个组直接决出冠军。
- 2、4、8 等二的幂次个组，可选择“每组决出一名出线者”或“继续决出总冠军”。
- 其他组数以每组产生一名出线者为目标。例如分 5 组，得到 5 个出线名额。
- 决冠军赛制可按支持的决赛阶段人数选择“不加赛名次”“三、四名加赛”或“第三至第八名排位赛”。

在“随机参数与重新抽签”中核对随机数种子。随机数种子是复现抽签的字符串参数，可使用公开约定的文字或十六进制字符串，与报名表中的种子选手分别设置。相同有序名单、设置、随机数种子和算法版本可复现相同结果；原始文件哈希用于核对文件，抽签输入哈希用于核对设置与有序名单。

### 公开执行并确认

1. 向参赛代表展示名单、种子、赛制、组数和随机数种子。
2. 点击“开始公开抽签”。程序生成并保存“抽签结果（待确认）”。
3. 核对分组、首轮对阵、轮空、出线目标和名次加赛；可先导出待确认材料供复核。
4. 点击“确认本项目抽签”，保存正式签表。
5. 多项目逐项完成。底部“还有 N 项未确认 · 查看”可展开未完成清单，点击项目即可返回其检查区域。

修改抽签设置后，点击“按当前设置重新抽签”才会生成新结果。导出使用已保存的结果。“放弃未保存的修改”恢复当前结果所用设置；尚未抽签时恢复本次编辑的初始设置。

全部确认后，“继续安排比赛时间”进入赛程设置。只做公开抽签时，也可先导出正式材料并关闭比赛；再次打开文件会保留确认结果。

### 导出抽签结果

点击“导出抽签结果…”，选择范围和格式，再点击“选择导出文件夹…”。

| 选项 | 内容 |
| --- | --- |
| 当前项目 | 导出当前项目的已保存签表。 |
| 全部项目 | 多项目赛事中可用；所有项目须均已抽签，并同为待确认或同为已确认。 |
| Excel 工作簿 | “对阵表”“抽签设置与审计信息”“当前名单”三张工作表。 |
| A4 PDF | 适合打印；淘汰赛可设置拼页行数和列数，1 × 1 为单页。 |
| PNG 图片 / JPEG 图片 | PNG 使用透明背景；JPEG 使用白底，适合电子公示和分享。 |
| 全部格式 | 一次生成以上四种格式。 |

抽签文件名由项目名、项目标识和“待确认抽签结果”或“已确认抽签结果”组成。材料内也标明确认状态。多项目导出分别生成各项目文件，全部确认时默认选择全部项目。

循环赛 PDF 包含封面总览及分组页面；淘汰赛拼页按设置切分。打印前检查文字大小和连接线，人数较多时增加分页。

遇到同名文件时，程序列出本次替换范围，点击“替换这些文件”才覆盖。取消设置、文件夹选择或替换确认会保留已有文件。导出过程中若切换赛事、项目或离开页面，需要重新发起请求。

### 更正已确认抽签

在“抽签记录与更正”查看随机种子、输入哈希、算法版本、生成和确认时间。整场赛事尚无赛果时，可填写原因、确认作废范围，再点击“解除确认并作废相关赛程”。这会作废本项目签表和比赛关系，以及整场赛事的赛程；其他项目签表保留。随后重新检查名单、抽签、确认并生成赛程。已有赛果时，该更正入口不可用。

## 4. 安排赛程

全部项目抽签确认后，填写比赛日期、每天开始和结束时间、场地及各项目基础单场时长。点击“检查并生成赛程”，程序统一安排整场赛事，完整校验后保存。生成成功后从“查看赛程板”进入赛程摘要。

常用操作包括：

- “添加比赛日”：新卡片放在顶部，默认取已有最晚日期的次日。
- 日期框和时间框：点选日期，或选择小时、分钟并确认。
- “选择场馆与场地”：勾选实际可用的内置场地，或输入自定义场馆和场地。
- “沿用上一个比赛日的场地和时间”：在选择窗口核对后应用日期上最近的前一天配置。
- “高级排程设置”：填写不可用时段、裁判人数及分时人数；单项赛还可设置最少休息、每日场次上限和淘汰赛分段时长。
- “将各项目决赛安排在最后一个比赛日”：多项目赛事可选择将冠亚军决赛固定在所填日期中的最晚一天。

页面的容量估算帮助判断资源规模。排程成功还须满足前后轮次、场地、裁判、选手身份、休息和每日场次等限制。团体项目按一场完整团体对抗安排，应填写包含各盘比赛、热身和换场的时长；队员个人场序由组织方安排。

设置修改在成功生成后保存。“放弃未保存的修改”经确认恢复已保存设置。生成失败保留原赛程，并显示未安排场次和原因。已有赛果后，可在赛程板调整未完成比赛。

详细日期行为、场馆清单、时长示例和排程诊断见[赛程编排说明](scheduling.md)。

### 查看和调整赛程板

点击“打开独立赛程板 ↗”，在独立窗口查看“时间 × 场地”总表。窗口默认最大化，可调整大小或放到第二块屏幕；主窗口仍可继续操作。当前赛事会话内保留日期、缩放和紧凑／详细显示选择，关闭赛程板后可随时重开。

点击比赛卡片查看详情，再点击“调整时间与场地”。选择目标日期、开始时间和场地后，点击“查看本场调整方案”或“查看连锁调整方案”，核对所有原位置和新位置，再点击“确认并保存调整”。连锁方案尝试移动本项目受影响的后续比赛，并检查全部项目的资源和选手约束。

也可拖动未完成比赛，松开时重新校验，合法即保存。卡片悬停反馈用于查看目标是否可放置；最终以保存结果为准。“撤销移动”可在当前允许的状态下回退上次手动调整，整次连锁移动一起撤销。已有赛果的场次锁定；导入赛果、重新读取、恢复或切换赛事后，请按当前状态重新创建调整方案。

### 查看选手兼项

至少两个项目已导入名单时显示“选手兼项”入口，全部项目名单就绪后可打开。入口位于名单页、排程设置页和赛程摘要页；只做公开抽签也可用。

左侧按姓名或学号搜索跨项目选手，右侧核对报名项目、搭档和单位。生成赛程后，窗口增加日期、时间、场地、对手、完成状态和休息间隔排序；“已确定参加的比赛”与“后续可能参加”分开展示。

点击“在赛程板中定位”会打开或激活赛程板，切换日期并滚动到目标比赛。卡片的“当前定位”标记持续显示，点击另一场或“取消定位”可切换或清除。定位只改变视图。

兼项窗口中的冲突、休息不足和最短间隔依据已确定比赛计算；潜在晋级场次保留在“后续可能参加”中。最短间隔取同日相邻的确定比赛，负数表示重叠，没有可比较场次时显示暂无。报名项目数按报名计算，淘汰后仍保留。窗口随名单、赛程和赛果更新，详细解释见[赛程编排说明](scheduling.md#选手兼项与负荷核对)。

## 5. 比赛现场

页面依次提供“1 导出比赛材料”“2 记录比赛结果”“3 查看比赛进展”三个页签。每次比赛日可按“导出材料 → 现场填写 → 检查并导入 → 查看进展 → 导出后续材料”的顺序工作。

### 先导出现场材料

1. 在“导出比赛材料”勾选一个或多个日期。
2. 多项目默认选择全部项目，也可在“高级导出设置”中选择一个项目；单项目自动使用当前项目。
3. 按需设置淘汰赛 PDF 的纵向页数、横向页数，以及此前待填记录的目标日期。
4. 核对范围并勾选确认，点击“生成现场比赛材料…”，在系统窗口选择保存文件夹。
5. 如有同名文件，核对清单并确认替换；成功后检查实际材料目录和文件列表。

材料包放在所选文件夹下的日期目录中。单日如 `10月5日男子单打比赛材料包`、`10月5日多项目合并材料包`；多日如 `10月5日-10月6日多项目合并材料包`。跨年范围会加年份。目录名保留本次所选日期范围；其中某天没有场次时，会跳过该日材料并在结果中说明。

| 材料 | 只选一个项目的文件名示例 | 选择多个项目的文件名示例 |
| --- | --- | --- |
| 完整带时间对阵图 | `男子单打带时间对阵图.xlsx` / `.pdf` | 每个选定项目各一份 Excel 和 PDF |

每日只有一份记录表，汇总当天所选项目，按计划日期、时间和已配置的场地顺序排列。只导出一个项目时使用该项目命名方式。项目名在清理文件名后重名时，以“（2）”“（3）”区分，单独导出该项目也保留编号。

带时间对阵图保留选定项目的完整签表；每日赛程、记录表和计分表按所选日期生成。全部所选日期均无可导出场次时，会提示调整范围。

材料包由表格、PDF 和说明文本组成；文件大小、哈希和导出范围保存在赛事文件的导出记录中。多项目检查报告的五张表分别为“检查总览”“当前赛程卡片”“检查明细”“选手每日负荷”“资源与日负荷”，检查范围为整场赛事。

导出前会检查全赛事硬约束。完成后可展开技术详情核对实际范围、跳过项、文件路径和审计状态。重复导出仅处理本次文件清单，目录中其他文件继续保留；需要整洁的新交付目录时可选择新的上级文件夹。部分文件发布失败的处理见[故障处理](troubleshooting.md#材料包不完整或不能覆盖)。

### 填写和导入记录表

保留导出的记录表原件，另存副本填写。工作表第 5 行是示例，真实比赛从第 6 行开始。A–M 列是默认打印区域，包括序号、日期、时间、进度、组别、对阵数据、比分、用时、场地、胜方和备注。N–T 列隐藏保存场次、赛事、项目和签表身份及胜方候选；U、V 列“结果类型”“实际比赛日期”需在电子表格中填写。

| 情况 | 比分 | 用时 | 胜方 | 结果类型 | 实际比赛日期 |
| --- | --- | --- | --- | --- | --- |
| 单局单项赛，A 获胜 | `21-19` | `18`、`18m` 或 `18分钟` | 下拉选择 A 的完整选项，或填 `A` | `正常`，留空也按正常处理 | 如 `2026-10-05` |
| 三局两胜，B 获胜 | `21-18, 16-21, 19-21` | 正整数分钟 | 下拉选择 B，或填 `B` | `正常` | 实际比赛日 |
| 团体赛，A 获胜 | `3-2` 等一组非平局总比分 | 正整数分钟 | A 的完整选项或 `A` | `正常` | 实际比赛日 |
| 弃权，A 获胜 | 可留空 | `0` | A 的完整选项或 `A` | `弃权` | 作出该赛果的日期 |
| 尚未比赛 | 留空 | 留空 | 留空 | 可留空 | 未知时留空 |

比分始终按 A–B 方向填写。单项赛支持一局非平局比分或已结束的三局两胜比分；团体赛使用一组总比分。程序检查格式、局数和胜方一致性，具体计分规程仍由裁判长核对。有胜方的行必须填写实际比赛日期，并使用已配置的比赛日；推荐输入 `yyyy-MM-dd` 文本或有效的 Excel 日期。仅填写比分、用时而没有胜方时，检查会提示该行仍为待赛。

同一张记录表包含前置比赛时，填写前置胜方后，后续对阵的胜者／负者公式会更新为真实参赛方。若前置场次在另一文件中，应先导入前置赛果后重新导出，或把依赖赛果一起选择导入。保存工作簿以保留公式计算结果；提示缺少公式缓存时，在 Excel 或 LibreOffice 中打开并保存后重新检查。

保持工作表名、隐藏标识和来源公式完整。胜方使用完整下拉选项或 `A` / `B`，只写姓名可能无法与真实参赛方对应。

导入步骤：

1. 打开对应赛事，在“记录比赛结果”点击“选择比赛记录表”，可多选多个项目和日期的文件。
2. 点击“检查记录表”，核对文件来源、工作表、行号，以及新增、重复、待赛和更正计数。
3. 处理所有阻断诊断。如需更正已有结果的比分、时长、类型或实际日期，勾选允许更正、填写原因，再检查一次。
4. 勾选本次操作确认，再点击“确认导入并保存”；内容全部已处理时，按钮显示“确认检查（无需保存）”。
5. 查看“本次操作的实际结果”和已记录场次，核对持久化结果。

同一文件内容按哈希识别，重复导入会跳过；同一批文件中同一场比赛的胜方、比分、时长、日期和类型须一致。胜负方冲突须先人工查清，普通元数据更正仅用于胜负双方保持一致的情况。合法待赛行会记录文件覆盖情况，赛果仍保持未完成；“已覆盖记录行数”与“已完成比赛数”分别统计。

### 查看比赛进展与更新材料

导入成功后，下游对阵按已保存赛果解析，已完成比赛锁定。“查看比赛进展”显示各项目记录情况，“查看赛程与后续对阵”返回赛程板。导入回执、更正前后值及原始记录可展开核对。

然后回到“导出比赛材料”，独立选择所需日期并导出最新材料。需要把以前合法导入为待赛、目前仍未完成的比赛放入某天材料时，启用“将此前未录入赛果的比赛补入本次材料”，并选择目标日。目标日须在本次导出日期内。

补入行保留原计划说明，目标记录日的时间和场地显示“待安排”。这项操作只决定材料收录范围；实际改期请使用赛程板，实际比赛日期由记录人员填写。已有有效待赛导入记录是补入依据，作废记录不参与。全部真实比赛均保存有效赛果后，赛事状态成为“已完成”。

### 打印前检查

每日赛程以起止时间段为行、场地为列，同一起止时间的场次放在同一行，阶段颜色辅助识别；行高按文字内容排版。Excel 另附赛程明细和参数，便于核对完整来源。

单场比赛计分 PDF 每场一页，预填项目、阶段、日期、计划时间、场地和已确定选手，未决双方姓名区留空；团体比赛计分 Excel 按团体子场版式分页。打印前检查纸张方向、重复表头、文字大小和对阵图连接线，多项目检查报告部分表使用 A3。

## 6. 完成与归档

全部项目抽签确认后即可查看“完成与归档”。页面汇总各项目进度、未录入赛果和最近手动备份。只做抽签时，可导出正式公示并留存备份；完整赛事可从“前往导出最终材料”进入现场材料页，按最终状态导出。

赛事完成状态由有效赛果计算。归档建议保存：赛事文件、已验证备份、原始名单、抽签公示及随机种子、填写后的记录表、最终材料和人工更正依据。点击“创建赛事备份”打开恢复面板，再点击“创建当前比赛的备份”，保存当前进度的独立副本。

## 7. 备份、恢复和错误处理

顶部“备份与恢复”可创建当前比赛备份，或把备份恢复到目标赛事文件。创建后核对提示中的已验证路径、赛事身份、保存进度和哈希；备份代表创建时的状态，之后的修改需要另外备份。

恢复可打开的赛事时：

1. 打开目标比赛，进入“备份与恢复”。
2. 点击“选择备份”，选择同一赛事的备份文件。
3. 点击“检查备份与恢复范围”，核对目标完整路径、赛事身份和备份进度。
4. 填写恢复原因，勾选确认，点击“确认恢复并保存”。

目标文件已经损坏时，仍可打开面板，勾选“赛事文件已经损坏、无法打开”，点击“选择损坏文件”明确目标，再选择备份并检查。由于目标身份可能无法读取，需人工核对路径和备份摘要。恢复会保留目标原状态副本并写入操作记录。

预览后来源文件或赛事状态变化时，需要重新检查。遇到“已保存但无法重读”，先用“重新读取赛事文件”核对已保存状态，再决定后续操作。完整的错误分类和证据保留方法见[故障处理](troubleshooting.md)。
