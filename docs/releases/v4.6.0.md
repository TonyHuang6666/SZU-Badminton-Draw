## 4.6.0

4.6.0 是当前 4.x 工作台的稳定收官版本。它不再扩展新的赛事形态，而是把 4.5.0 之后的跨平台统一、赛程约束、存档安全和工程维护成果集中验收并交付。

### 主要变化

- 移除历史 WPF 项目，Windows 与 macOS 统一使用 Avalonia 桌面主线。
- 新增单项目自定义编排，以及不可用场地时段、质量摘要等资源约束能力。
- 修复桌面应用启动闪退，并拆分主窗口、测试套件和多项目工作流，降低后续维护风险。
- 多项目排程现在会传播未决对阵的候选选手路径，在不误判互斥胜负分支的前提下保证跨项目冲突与最短休息约束。
- 加固多个赛事存档部分保存失败时的恢复边界：写入前逐个验证，后续写入失败时恢复已更新存档，恢复失败时报告可手工使用的备份路径。
- 更新 SQLite 原生依赖；CI 新增直接与传递 NuGet 依赖漏洞审计。
- 补充可重复执行的端到端赛事验收工具和调度不变量文档。

### 验证

- GitHub Actions Windows 与 macOS 双平台构建、测试和发布冒烟检查通过。
- 固定 .NET 8 SDK 完成锁定还原、NuGet 漏洞审计、Release 构建和全量测试：140/140 通过。
- 三份真实规模虚拟名单完成抽签、单项目排程、存档、多项目合并、材料包、赛果导入、后续对阵刷新和备份恢复链路，共覆盖 345 场比赛。
- 33 个 Excel 工作簿经 LibreOffice 重算，公式错误值为 0；28 个 PDF 共 713 页完成结构、字体、中文文本和代表性页面渲染检查。
- Windows `win-x64` 自包含单文件和 macOS Apple Silicon DMG 均由 `v4.6.0` 标签提交重新构建；SHA-256 见 Release 附件 `SHA256SUMS.txt`。

完整证据见 [`docs/acceptance/v4.6.0.md`](https://github.com/TonyHuang6666/SZU-Badminton-Draw/blob/v4.6.0/docs/acceptance/v4.6.0.md)。

### 已知边界

- macOS 应用未使用 Apple Developer ID 签名或公证，首次打开可能需要在系统安全设置中确认。
- Windows 包已通过 GitHub Actions 自动化构建、测试和发布检查，但本轮未在真实 Windows 桌面执行人工启动。
- 拖拽、撤销、连锁/跨日移动、深色模式、显示缩放和物理打印仍需在真实赛事前完成短版人工检查。
- 合并记录表只用于现场填写、打印和交接；赛果必须回灌到各项目自己的记录表。
