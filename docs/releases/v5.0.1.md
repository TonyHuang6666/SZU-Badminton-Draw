# 5.0.1 发布说明

发布日期：2026-10-06

发布标签：`v5.0.1`

源码提交：以 `v5.0.1` 标签指向的提交为准。

本页说明该标签对应安装包的功能与验证范围。仓库当前程序的操作见[使用说明](../usage.md)。

## 本次更新

- 改进全赛事排程搜索与容量利用，在满足比赛依赖、场地、裁判及选手约束的前提下提高早期比赛日利用率；“尽快完成”作为默认策略，多项目可选将各项目冠亚军决赛固定在最后一个比赛日。
- 内置深圳大学粤海校区运动广场东馆、丽湖校区至快体育馆和至畅体育馆，保留自定义场馆与场地；比赛日期、开始时间和结束时间使用选择器，新比赛日置于列表顶部。
- 赛程板改为独立窗口，支持日期切换、缩放、拖动、跨日移动、连锁调整与撤销；选手兼项面板可在名单阶段核对报名，并在排程后定位比赛。
- 现场材料沿用中文业务文件名，按比赛日合并赛程记录表并保留晋级公式；单项目与多项目材料名称、说明和检查报告按实际范围生成。
- 简化比赛现场、排程和创建赛事页面；团体赛隐藏个人休息、每日场次与分段时长等不适用设置，并修正名单行对齐与单项目提示。
- 界面改用深圳大学紫红色系，更新应用图标和最近比赛图标，最近列表显示最后打开或保存时间。
- 顶部新增“帮助”和“模板导出”。帮助窗口内置程序介绍、使用帮助与技术参考，支持搜索、跨段落选择及复制；模板导出提供参赛名单、空白单场比赛计分表和空白团体比赛计分表。
- 重写当前使用、排程、规则、算法、架构、构建和故障处理文档，并在 README 中补充项目起源与自主研发记录。

## 兼容性

- 工作区 schema 保持为 500，5.0.0 创建的 `.szbd` 赛事文件可由 5.0.1 继续打开。
- 4.x `.szbd` 存档不由 5.0.1 读取或迁移；旧赛事继续使用对应 4.x 版本打开。
- 正式平台范围为 Windows x64 与 Apple Silicon macOS；Linux 未纳入本版本分发验证。

## 安装包与验证

发布附件提供 Windows x64 自包含包和 Apple Silicon macOS DMG，见 [GitHub Release](https://github.com/TonyHuang6666/SZU-Badminton-Draw/releases/tag/v5.0.1)。`SHA256SUMS.txt` 用于核对附件完整性。

发布工作流在 Windows 与 macOS 上执行锁定还原、直接与传递依赖审计、Release 构建、1,852 项自动化测试及平台打包。macOS 任务同时执行打包安全测试、应用签名检查和 DMG 校验。

安装与现场使用范围：

- macOS 应用采用 ad-hoc 签名，Developer ID 签名、公证及 stapling 尚未完成，首次打开可能需要在系统安全设置中确认。
- Windows 真机人工界面验收、Microsoft Excel 重算、物理打印及完整 PDF 人工视觉矩阵尚未完成。
- 多页签表与宽记录表应在目标电脑上检查打印效果。

构建与复验命令见[构建说明](../build.md)，当前操作流程见[使用说明](../usage.md)。
