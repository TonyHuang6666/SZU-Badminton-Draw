# 5.0.4 发布说明

发布日期：2026-10-23

发布标签：`v5.0.4`

源码提交：以 `v5.0.4` 标签指向的提交为准。

## 本次更新

- “比赛现场 → 记录比赛结果”新增独立的现场记录表窗口。选择胜方和比赛结果后自动保存；比分与时长可留空，并可稍后补齐。
- 新增逐日结果确认。现场窗口只开放已确认日期和当前待确认日期；当天全部比赛有赛果，或逐场登记经裁判长同意的延期及原因后，才能确认当天并开放下一比赛日。
- 确认前预览延期比赛及受影响的后续场次。有效调整与当天确认一并保存；无法找到完整合法赛程时，原赛程保持不变。
- 旧 Excel 赛程记录表仍可集中导入。已明确批准延期的比赛，其实际比赛日期须晚于延期确认日。

## 安装与兼容性

赛事文件 schema 仍为 500。发布附件提供单独下载的 Windows x64 自包含 `BadmintonDraw.Desktop.exe` 和 Apple Silicon macOS DMG，并附 SHA-256 校验值；Windows EXE 不压缩、不附带 PDB。macOS 包采用 ad-hoc 签名，未进行 Developer ID 公证，首次打开可能需要在系统安全设置中确认。

延期只使用已配置的比赛日。最后一个已配置比赛日存在未完成场次时，程序会阻止当天确认；建议开赛前设置备用比赛日。已有赛果时不能通过重新生成赛程新增日期。

自动化检查覆盖锁定还原、依赖审计、Release 构建、测试和两个平台的打包。Windows 真机操作、Microsoft Excel 重算、物理打印和完整 PDF 人工视觉检查仍需在目标环境完成。构建与复验命令见[构建说明](../build.md)。
