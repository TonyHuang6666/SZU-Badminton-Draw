# 5.0.2 发布说明

发布日期：2026-10-22

发布标签：`v5.0.2`

源码提交：以 `v5.0.2` 标签指向的提交为准。

## 本次更新

- 程序顶部新增“联系方式”，可在独立窗口离线查看深大羽协官方微信和作者 Tony Huang 的微信二维码。
- 移除现场材料摘要与赛果记录等文本区域的冗余悬停提示；原有文字选取及右键“复制完整文本”继续可用。
- 仓库附带独立的微信小程序基础工程与开发说明；本次桌面安装包不包含小程序后端。

## 兼容性与安装

赛事文件 schema 仍为 500，5.0.0 和 5.0.1 的 `.szbd` 文件可继续由本版本打开。正式安装包提供 Windows x64 与 Apple Silicon macOS 版本；Linux 不在本次分发范围。

发布附件及其 SHA-256 校验值见 [GitHub Release](https://github.com/TonyHuang6666/SZU-Badminton-Draw/releases/tag/v5.0.2)。macOS 包仍采用 ad-hoc 签名，未进行 Developer ID 公证，首次打开可能需要在系统安全设置中确认。

自动化检查覆盖锁定还原、依赖审计、Release 构建、测试及 Windows/macOS 打包。Windows 真机操作、Microsoft Excel 重算、物理打印和完整 PDF 人工视觉检查不由 CI 代替。构建与复验步骤见[构建说明](../build.md)。
