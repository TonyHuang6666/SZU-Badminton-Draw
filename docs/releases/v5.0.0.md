## 赛事流程

程序按“比赛概览 → 准备名单 → 公开抽签 → 安排赛程 → 比赛现场 → 完成与归档”组织操作。一份 `.szbd` 赛事文件包含所有项目、名单、抽签、赛程、赛果和审计记录。

创建比赛时选择团体赛或单项赛，以及“先完成公开抽签”或“从抽签到现场，筹备整场比赛”。单项赛可包含男子单打、女子单打、男子双打、女子双打和混合双打中的一至五项。

名单导入、执行抽签、确认结果和材料导出各有独立操作。完成公开抽签后可以保存退出，之后打开同一赛事继续筹备。

## 公开抽签

- 支持淘汰赛、循环赛、分组、种子设置和公开随机种子。
- 抽签结果分为待确认与已确认两种状态，材料包含对应状态标记。
- “导出抽签结果…”窗口集中设置项目范围、Excel / A4 PDF / PNG / JPEG / 全部格式及 PDF 分页。
- 多项目全部确认时，默认选择全部项目；全部范围要求各项目已抽签且确认状态一致。
- “放弃未保存的修改”在抽签设置有修改时显示，执行后读取当前赛事已保存的设置。

## 赛程编排与查看

- 单项目与多项目使用统一排程入口，共享比赛日、场地和裁判容量。
- 排程默认优先使用较早可用时段。多项目可勾选将各项目冠亚军决赛安排在最后一个比赛日；程序在生成及手动调整时检查该要求。
- 比赛日期使用日历选择器，每天开始和结束时间使用 24 小时时间选择器。新添加的比赛日位于编辑列表顶部。
- 内置粤海校区运动广场东馆羽毛球场 32 片、丽湖至快体育馆 12 片、至畅体育馆 10 片，支持自定义场馆与场地。
- “沿用上一个比赛日的场地和时间”按日期寻找最近的较早比赛日，确认后应用场地与开始、结束时间。
- 赛程板为独立窗口，提供日期、缩放、紧凑／详细显示、撤销和调整工具。场地标题与时间列固定显示，比赛可拖动、跨日移动或连锁调整。
- “选手兼项”与“查看赛程板”并列；名单阶段可查看兼项报名，排程后可查看确定比赛、休息和冲突。定位比赛后，赛程板持续显示整卡强调及“当前定位”标记。

## 现场材料与赛果

“比赛现场”包含“导出比赛材料”“记录比赛结果”“查看比赛进展”三个页签。生成材料时调用系统文件夹选择器，并对本次同名文件替换逐项列出确认范围。

材料按所选日期建立文件夹。实际选择一个项目时使用项目名称，例如 `10月5日男子单打比赛材料包`；多个项目使用 `10月5日多项目合并材料包`。

每日材料包括赛程安排表 Excel／PDF、一份覆盖所选项目的赛程记录表和计分材料；带时间对阵图按项目导出。多项目材料包另含排程检查报告。材料说明列出项目、日期和输出文件，文件哈希与导出范围保存在赛事审计中。

赛程记录表采用日期标题、阶段配色、填写示例、胜方选择及同表晋级公式。公式关联本表包含的前置场次；其他来源显示导出时的对阵或来源说明。主表默认打印 A–M 列，结果类型和实际比赛日期位于 U–V 列。

赛果导入先检查记录表和来源，再确认保存。更正比分、用时或日期需要填写原因；相反胜方、无效来源及互相冲突的记录会被拦截。保存后，累计赛果用于刷新后续对阵与材料。

## 备份与恢复

顶部“备份与恢复”可检查备份并恢复当前比赛，也可处理无法打开的损坏赛事文件。恢复前展示来源、目标和检查结果，确认后执行。

“完成与归档”显示实际完成情况和未完成场次，提供材料与备份入口。赛事完成状态由赛果决定。

发布附件提供 Windows x64 自包含包和 macOS Apple Silicon DMG，见 [GitHub Release](https://github.com/TonyHuang6666/SZU-Badminton-Draw/releases/tag/v5.0.0)。

安装与现场使用范围：

- macOS 应用采用 ad-hoc 签名，Developer ID 签名、公证及 stapling 尚未完成。
- Windows 真机人工界面验收、Microsoft Excel 重算、物理打印及完整 PDF 人工视觉矩阵尚未完成。
- 多页签表与宽记录表应在目标电脑上检查打印效果。
- 正式平台验收范围为 Windows 和 macOS。

候选阶段的具体环境、产物哈希和检查范围见[资料归档](../archive/index.md)；构建与复验命令见[构建说明](../build.md)。
