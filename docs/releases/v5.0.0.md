## 5.0.0（发布说明草案）

5.0.0 重做了赛事工作流：先决定举办团体赛还是单项赛、包含哪些项目，以及本次只做公开抽签还是筹备完整赛事，再进入名单、抽签、统一排程和现场执行。本文是候选 Release 说明，正式发布前仍需完成远端 CI 与真实 Windows 门禁。

> 状态说明：5.0 尚未正式发布。2026-10-03 的赛事助手式 GUI 本地构建、全量回归及 macOS 代表页面检查记录见[当日 GUI 验证报告](../acceptance/v5-gui-2026-10-03.md)，不代表此后独立赛程窗口改动已完成验证。当时未推送、未运行远端 CI、未完成 Windows 真机验收。以下“本地候选验证”仍单独保留历史提交 `9c476ab` 的证据。

### 核心变化

- 一个 `.szbd` 工作区承载整场赛事；团体赛与单项赛不能混排，单项赛可包含一至五个项目。
- 新建时显式选择“仅公开抽签”或“完整赛事筹备”。导入名单不自动抽签，抽签也不自动排程。
- 开始公开抽签后保存“抽签结果（待确认）”，确认和导出分别执行，可配合公开线上会议完成抽签并在之后继续办赛。按当前设置重新抽签会实际生成并保存新的待确认结果。
- 单项目、多项目默认尽快安排，共享比赛日、场地、裁判容量、休息和每日场次限制；界面不再提供均衡、自定义、累计阶段进度等选项。可勾选将各项目冠亚军决赛固定在最后比赛日，该要求在生成和手动调整时均强制校验。
- 引入无时间比赛关系图、全局赛程板、未决胜负路径约束、容量预检、质量诊断，以及单场/连锁/跨日移动和撤销。
- 现场执行页统一记录表检查与赛果导入、材料包导出、审计历史和健康/损坏存档恢复。
- 赛果更正需要明确确认和原因；重复、冲突、过期、畸形及来源不一致的数据不会静默覆盖工作区。
- 删除 4.x 的旧窗口、旧单项目调度、多存档合并和旧记录路径；Windows 与 macOS 共用 Avalonia 入口。

### 本地 GUI 更新

- 比赛日期改为带日历图标的日期选择器，支持点选、切换月份／年份和键盘操作；选择只修改草稿，滚动页面不会误改日期，已有时间和场地保持不变。
- 新添加的比赛日置顶并自动进入视野，默认接续已有最晚日期；编辑日期不让卡片跳动，重新载入按日期倒序显示，实际排程、导出及沿用前一比赛日场地和时间的日期规则保持不变。
- 每天开始／结束时间改为 24 小时制的小时、分钟选择器，确认后应用，取消保留原值；结束时间不晚于开始时间时给出明确提示，失败不改存档。高级时段设置保持原有输入方式。
- 时间框使用完整的“09:00”显示与钟表图标，取消分栏并统一输入框的字体、留白及明暗主题配色；保留原有时间选择行为。
- 以比赛概览、准备名单、公开抽签、安排赛程、比赛现场、完成与归档六步导航组织任务；赛程板归入安排赛程步骤。
- 主窗口赛程板页改为摘要和打开赛程板、返回设置、前往材料的入口。赛程板使用独立非模态窗口，默认最大化、可调整大小；重复打开激活已有窗口，关闭窗口不关闭赛事。当前赛事会话内保留日期、缩放和显示密度，切换工作区时关闭旧窗口。
- 赛程窗口集中显示日期、缩放、紧凑／详细和撤销工具栏，冻结顶部场地标题与左侧时间列；紧凑卡片按项目着色并保留文字标签。整分钟显示 `HH:mm`，非零秒仍保留。选中卡片先查看，再明确打开调整浮层；操作状态在窗口内显示，主窗口导航及赛事数据同步。保留拖动、手动、连锁、跨日、撤销和全赛事后端校验，不改变调度算法或存档结构。
- 主页面恢复“选手兼项”入口，与“查看赛程板”并列，赛程摘要页也提供同级入口，不再藏在赛程板内。独立双栏窗口显示报名项目、确定比赛、完成状态、同日最短排定间隔和冲突／休息不足提醒，支持休息排序；定位比赛时才打开或激活赛程板，保留排程设置草稿。移动、撤销和赛果更新后同步刷新，保留选手和排序；两个窗口可分别关闭，切换赛事或关闭主窗口时关闭旧窗口。未决晋级场次单独折叠展示，不混入确定场次和风险统计；确定比赛的休息检查覆盖非相邻场次与跨午夜间隔。
- “准备名单”阶段导入全部项目后即可查看兼项报名，支持姓名／学号搜索、逐项搭档核对及身份疑点提示；只做抽签的赛事也可用。各页面仅在至少两个项目已导入名单时显示兼项入口，单项目不显示。未排程时不显示场次、冲突和休息统计；生成或清空赛程时，同一窗口自动切换内容，保留报名信息。
- 赛程板定位改为持续的整卡强调底色、边框和“当前定位”标记，配合紧凑的位置说明与“取消定位”，不再只闪亮边框 1.5 秒。缩放、主题切换和赛程刷新保留有效定位，切换目标或取消时才解除。
- 首页突出创建和继续比赛；首页、新建流程隐藏先前比赛的标题、导航与路径。最近列表可移除入口，赛事文件不会因此删除。
- 新建向导使用带说明的比赛类型与目标选项；抽签、确认、导出和继续排程分别执行，只做公开抽签时可导出后停止。
- 公开抽签页底统一为“导出抽签结果…”入口，范围、格式和 PDF 分页集中在设置窗口。全部确认的多项目默认全部，否则默认当前；全部项目必须已抽签且确认状态一致才能一起导出，单项目不重复显示全部范围。包含 PDF 时显示可展开的分页设置，选择导出文件夹后按具体文件确认同名替换。
- 待确认结果也可导出，材料标明“抽签结果（待确认）”，文件名带“待确认抽签结果”，不会自动确认。取消设置不导出、不保存存档或改变上次设置；会话、项目或页面变化后旧请求失效。完整筹备赛事全部确认后，以继续安排比赛时间为主要操作；只做公开抽签时以导出为主要操作，进入赛程无须先导出。
- 常用排程设置优先显示；不可用时段、裁判容量、休息、每日场次上限和分段时长等在高级设置中保留。折叠不会清空草稿。
- 单项目隐藏决赛末日选项，重新生成时不启用隐藏约束；旧赛程不自动改变。时长设置改为上方基础时长、下方进入前 N 名起的单独时长，含该轮；加载旧设置保留实际前后期时长。
- 抽签设置的恢复按钮改为“放弃未保存的修改”，仅实际改动时显示，改回原值或放弃后隐藏。未抽签时保留初始随机种子，放弃操作不重新抽签或修改存档；设置冲突仍保留恢复入口。
- 排程设置页以“放弃未保存的修改”替代“重新载入设置”：仅有未保存修改或草稿冲突时启用，明确确认后才恢复已保存设置；取消保留输入，不改变现有赛程。
- 比赛日通过“选择场馆与场地”弹窗选择深大粤海东馆、丽湖至快及至畅体育馆的具体场地，保留自定义场馆和编号生成；新比赛日不默认占用任何场地。“沿用上一个比赛日的场地和时间”按日期选择最接近的较早比赛日，经原有场馆与场地窗口确认后，一并应用场地及每天开始、结束时间；保留当前日期，不复制来源的不可用时段或裁判设置。取消或窗口失效均不应用场地和时间。不可用时段从当日场地中选择，更换场地影响已有时段时仍须明确确认。内置场地保存与导出包含场馆简称，每日赛程 Excel 附使用场馆的全名说明。本项不包含分校区预选或跨校区交通约束。
- 比赛现场默认先导出材料，再记录比赛结果、查看比赛进展与后续对阵。高级导出选项按需展开，范围确认、诊断、更正前后值和实际操作结果仍保留。
- 比赛现场的导出／导入核对说明与确认勾选移入滚动内容，固定底栏缩为单行状态和操作按钮；导入确认仅在当前检查结果有效时显示。保留导出范围确认、导入及赛果更正保护，进展页保持只读。
- 比赛现场顶部压缩为标题、记录进度及备份入口同一行，三个页签紧接其下。删除预填导出目录，点击生成后直接调用系统文件夹选择器；取消或选择期间来源／范围变化不会发起旧请求，原有同名替换确认、中文文件名、合并记录表及晋级公式保持不变。
- 现场材料恢复 4.6 的中文命名与打印布局：所选文件夹内生成按所选日期命名的材料包，每日提供时间×场地赛程 Excel／PDF、一份覆盖所选项目的合并赛程记录表和计分材料，不另生成分项目记录表；记录按比赛时间和已配置场地顺序排列，完整带时间对阵图仍按项目命名。再次导出使用相同目录，按具体文件确认替换；同名项目稳定编号。成功界面显示实际材料目录和文件名，校验与审计信息可展开查看。
- 合并记录表主表沿用 4.6 的日期标题、列名、“对阵数据”合并表头、列宽、行高、填写示例和阶段底色，默认打印 A–M 列；5.0 所需的结果类型与实际比赛日期保留在右侧 U–V 列供电子填写，内部导入标识继续隐藏。
- 记录表恢复同表晋级公式、阶段配色和填写示例，保留 5.0 赛果导入所需字段。公式仅关联本表包含的前置场次；跨日期筛选未包含的场次保留导出时的对阵或来源说明，不建立跨文件公式。
- 备份与恢复区分当前比赛恢复和无法打开的损坏文件恢复；完成与归档显示真实未完成场次，备份不会改变赛事完成状态。
- 统一浅色与深色外观、页面层级与底部操作区。本次改版保留原有数据格式、调度规则、确认和恢复保护。

### 不兼容变化

- 5.0 工作区 schema 为 500，不读取或迁移 4.x 存档。
- 不再存在“先分别排项目、再合并多个存档”的操作方式。
- 团体赛和单项赛必须建立为不同赛事；需要查看旧赛事时继续使用对应旧版本。
