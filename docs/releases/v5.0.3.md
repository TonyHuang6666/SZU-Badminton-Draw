# 5.0.3 发布说明

发布日期：2026-10-22

发布标签：`v5.0.3`

源码提交：以 `v5.0.3` 标签指向的提交为准。

## 本次更新

- 内置帮助文档在构建时转换为程序可读取的数据。帮助窗口继续提供离线阅读、正文搜索、文档跳转、字号调整和文字复制。
- 桌面程序及安装包不再携带 Markdown 转换库 Markdig；该库的许可证声明保存在构建工具中。
- 打包检查会检测实际输出中的 Markdig 组件、构建工具和旧版许可证文件，避免复用输出目录时误带入安装包。

## 安装与兼容性

赛事文件 schema 仍为 500，可继续打开 5.0.x 赛事文件。发布附件提供 Windows x64 自包含包和 Apple Silicon macOS DMG，附 SHA-256 校验值。macOS 包采用 ad-hoc 签名，未进行 Developer ID 公证，首次打开可能需要在系统安全设置中确认。

自动化检查覆盖锁定还原、依赖审计、Release 构建、测试以及两个平台的打包。Windows 真机操作、Microsoft Excel 重算、物理打印和完整 PDF 人工视觉检查仍需在目标环境完成。构建与复验命令见[构建说明](../build.md)。
