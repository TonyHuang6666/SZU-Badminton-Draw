# 深大羽协 · 赛事助手

面向 Windows 和 macOS 的校园羽毛球赛事工作台，覆盖名单核对、公开抽签、赛程编排、现场材料、赛果导入和备份恢复。

[使用说明](docs/usage.md) · [赛程编排](docs/scheduling.md) · [故障处理](docs/troubleshooting.md) · [文档中心](docs/index.md)

## 项目起源与自主研发

本项目由 Tony Huang 围绕深圳大学羽毛球协会的校园赛事组织需求发起并持续开发。项目的早期原型是 C++ 抽签分组程序 [BFSZU.cpp](https://github.com/TonyHuang6666/Badminton-Draw/blob/main/BFSZU.cpp)，面向单项赛和团体赛，提供名单输入、随机分组、种子分配、轮空与首轮对阵安排，以及抽签结果的文本导出，帮助赛事组织者完成抽签和后续制表工作。

原型源码的开头说明记载了作者身份及 **2023 年校长杯筹备**的开发背景；该文件的 Git 提交记录可追溯至 **2023 年 8 月 27 日**的[首次提交 `616dc10`](https://github.com/TonyHuang6666/Badminton-Draw/commit/616dc1052e3c4ec38665e73d9d9a2de0a51af67c)。[该次提交中的原型源码](https://github.com/TonyHuang6666/Badminton-Draw/blob/616dc1052e3c4ec38665e73d9d9a2de0a51af67c/BFSZU.cpp)保留了当时的设计说明和实现，可作为了解项目起点的可核查资料。

项目的自主研发工作围绕赛事业务规则、组织流程及其软件实现展开。当前程序采用 C#/.NET 与 Avalonia，研发范围覆盖可复现抽签、种子保护与同单位分散、比赛依赖建模、多项目赛程编排与约束校验，并延伸至赛事存档、现场材料、赛果导入和桌面交互。具体实现与验证依据可查阅本仓库源码、测试、提交记录，以及[算法说明](docs/algorithm.md)和[系统架构](docs/architecture.md)。从抽签原型到赛事工作台，项目持续围绕校园羽毛球比赛的实际组织需求完善功能。

## 主要功能

- 一份 `.szbd` 赛事文件保存整场比赛的项目、名单、签表、赛程、赛果和操作记录。
- 团体赛以参赛单位为队伍；单项赛支持男子单打、女子单打、男子双打、女子双打和混合双打，可选择一至五项。
- 公开抽签支持分组、种子保护、同单位分散和公开随机种子；抽签结果经确认后用于排程，并可导出 Excel、PDF、PNG 和 JPEG。
- 赛程统一考虑日期、时间、场地、裁判容量、比赛依赖及单项赛选手负荷，优先使用较早的可用时段。多项目单项赛可选择将各项目冠亚军决赛安排在最后一个比赛日。
- 内置深圳大学粤海校区运动广场东馆羽毛球场，以及丽湖校区至快、至畅体育馆；支持自定义场馆和场地。
- 独立赛程板支持日期切换、缩放、紧凑和详细显示、拖动、跨日移动、连锁调整与撤销；选手兼项面板提供报名核对、赛程明细和比赛定位。
- 现场材料按日期组织，同一天的所选项目共用一张赛程记录表，包含同表晋级公式。填写记录表后，可检查并导入赛果、刷新后续对阵。
- 顶部“备份与恢复”提供备份检查和恢复；“完成与归档”展示比赛进度及资料留存入口。
- 顶部“帮助”支持离线阅读、搜索文档及调整字号；“模板导出”提供通用参赛名单 Excel 和单场、团体两种空白计分表，支持单独或批量导出。

## 开始使用

下载与安装包说明见 [5.0.1 发布说明](docs/releases/v5.0.1.md)。本 README 和主题文档描述仓库当前程序，安装包功能以对应发布标签为准。

1. 点击“创建一场新比赛”，填写比赛名称，选择团体赛或单项赛、筹备目标和参赛项目，保存赛事文件。
2. 在“准备名单”中按项目导入 Excel 名单，核对选手资料和种子。
3. 在“公开抽签”中执行并确认各项目的抽签结果，导出公示材料。
4. 在“安排赛程”中设置比赛日期、可用时间和场地，点击“检查并生成赛程”。
5. 在“比赛现场”导出材料、记录比赛结果并查看比赛进展。
6. 在“完成与归档”核对进度，导出所需材料并创建备份。

只负责公开抽签时，选择“先完成公开抽签”。完成公示后可保存并退出，稍后打开同一赛事文件继续安排赛程。示例名单见 [samples/v5](samples/v5/README.md)。

首页的“最近的比赛”显示最近一次打开或保存时间。点击“继续”返回赛事，悬停可查看完整路径和时间；移除条目只影响最近列表。

## 材料导出

“公开抽签”中的“导出抽签结果…”集中选择项目范围、文件格式和 PDF 分页。材料清楚标明“待确认”或“已确认”，导出目录通过系统文件夹选择器确定。

“比赛现场”按所选项目和日期生成材料包：

| 内容 | 格式 |
| --- | --- |
| 每日赛程安排表 | Excel、PDF |
| 每日赛程记录表 | Excel |
| 单项赛单场比赛计分表 | PDF |
| 团体比赛计分表 | Excel |
| 各项目带时间对阵图 | Excel、PDF |
| 材料包说明 | TXT |
| 多项目排程检查报告（选择多个项目时） | Excel |

单项目示例为 `10月5日男子单打比赛材料包/10月5日男子单打赛程记录表.xlsx`；多项目示例为 `10月5日多项目合并材料包/10月5日合并赛程记录表.xlsx`。记录表的公式、填写字段、结果导入和后续比赛日材料操作见[使用说明](docs/usage.md)。

## 本地开发运行

使用仓库 `global.json` 指定的 .NET SDK，在仓库根目录执行：

```sh
dotnet restore BadmintonDraw.sln --locked-mode -p:Configuration=Release
dotnet build BadmintonDraw.sln -c Release --no-restore
dotnet run --project src/BadmintonDraw.Desktop/BadmintonDraw.Desktop.csproj -c Release --no-build
```

`--no-build` 运行已有构建产物。修改源码后先完成 Release 构建，再使用这条命令启动。

测试、依赖审计、端到端验收和平台打包见[构建说明](docs/build.md)。
