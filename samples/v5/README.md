# v5 虚拟验收名单

这些 `.xlsx` 文件由 v5 端到端验收工具实际生成并成功导入，只包含虚拟姓名、学号和学院信息。

| 文件 | 行数 | 用途 |
| --- | ---: | --- |
| `公开抽签_男单名单.xlsx` | 8 人 | 单独公开抽签、导出未确认预览和已确认结果 |
| `完整赛事_男单名单.xlsx` | 8 人 | 单项目完整赛事流程 |
| `校长杯_男单名单.xlsx` | 32 人 | 三项目全局编排中的男单项目 |
| `校长杯_男双名单.xlsx` | 16 对 | 三项目全局编排中的男双项目 |
| `校长杯_混双名单.xlsx` | 16 对 | 三项目全局编排中的混双项目，并与其他项目共享选手身份 |
| `完整团体赛名单.xlsx` | 29 队 | 团体循环赛和团体记分表 |

同一工作区只能是单项赛或团体赛；`校长杯_*` 三份名单应在一个单项赛工作区中分别导入三个项目。`B1-C8` 不会被自动展开为场地范围，如需多个场地请写成 `B1, B2, ...`。

## 推荐练习顺序

### 只做公开抽签

1. 新建单项赛，工作目标选择“仅公开抽签”。
2. 添加男子单打项目，导入 `公开抽签_男单名单.xlsx`。
3. 主动生成预览、导出未确认预览、确认抽签，再导出正式材料。
4. 关闭并重新打开赛事，确认签表仍在且没有赛程。

### 单项目完整赛事

1. 新建单项赛，工作目标选择“完整赛事筹备”。
2. 导入 `完整赛事_男单名单.xlsx`，完成抽签。
3. 设置日期、场地、裁判容量、休息与每日上限，生成赛程。
4. 导出材料、在副本中填写赛果并预览导入。

### 三项目统一排程

1. 在同一个单项赛赛事中添加男单、男双、混双。
2. 分别导入三份 `校长杯_*` 名单并逐项确认抽签。
3. 只设置一份全赛事资源和策略，不要创建三个赛事再合并。
4. 核对跨项目同学的学号是否一致，让兼项约束能够识别同一人。

### 团体赛

新建团体赛并导入 `完整团体赛名单.xlsx`。当前团体赛以队伍对抗作为一个比赛节点和总赛果单位，不模拟每场团体对抗内部的单打、双打子场及上场名单。

完整操作和错误处理分别见[使用说明](../../docs/usage.md)与[故障处理](../../docs/troubleshooting.md)。
