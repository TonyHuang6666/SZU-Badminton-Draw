# 测试样例名单

本目录提供几份虚拟名单，方便读者下载仓库后直接导入 GUI 测试。

v5 统一赛事流程请优先使用 [`v5`](v5/) 子目录中的六份已通过端到端验收的名单；旧样例继续保留，便于核对原有抽签布局。不要把旧样例的列结构或项目拆分方式当作 5.0 推荐流程。

| 文件 | 建议测试场景 |
| --- | --- |
| `深大羽协虚拟双打参赛名单_159人.xlsx` | 大规模双打淘汰赛、8 组、赛程编排、多格式导出、带比赛时间和场地的对阵表 |
| `深圳大学虚拟双打参赛名单_29人.xlsx` | 小规模双打、循环赛、A4 PDF 分页 |
| `深圳大学虚拟29学院参赛名单.xlsx` | 团体赛、学院/学部分组、循环赛矩阵 |

这些名单均为随机生成的虚拟数据，仅用于软件测试和演示。

建议先按照 [`v5/README.md`](v5/README.md) 选择场景，再对照[5.0 使用说明](../docs/usage.md)执行。样例“成功导入”只证明程序能读取指定格式，不代表样例中的种子、赛制、项目规模或组织参数适合真实赛事。
